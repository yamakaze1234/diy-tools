这几个词，认清就够了

商品链接 → 一组配置

比如一个主机商品页面，里面有“配置一、配置二、配置三”。

SPU → 链接的编号

用于记录整组商品身份。按实际商品填写，复制前核对。

SKU → 某个规格的编号

同一链接里的不同配置可能对应不同 SKU。必须填平台真实编号。

goodsid / ERP ID → 配件编号

比如某款内存的唯一商品编号。查成本、库存和监控时靠它匹配。

成本源 → 一件配件多少钱

人工核算价三店共用。ERP 成本和库存留在本机，各电脑自己读取。

输出源 → 配件怎么展示

管理本店配件的显示名称、质保、升级和加购资料，供配置调用。

卡住时，先看这里

点问题，直接看处理方法。

我保存了，同事为什么还看不到？

“保存本地配置”只保存到你的电脑。点顶部“同步”，进入多人同步窗口，点“立即同步”；让同事也同步一次。检查双方店铺、链接，以及是否还有待同步项目或冲突。

我只想改一套，为什么批量窗口显示很多套？

正在编辑哪一套，与勾选了多少套是两回事。先检查左侧勾选数量。批量应用前再看一次范围和差异预览。

图片里隐藏了配件，为什么成本还在？

“配置图显示”只控制图片上看不看得见。实际配置仍包含这件配件，成本、维护表输出和库存监控导出仍可能计入。

成本显示缺失或待补充，能当 0 元吗？

不能。先检查商品 ID，再更新 ERP 或补人工核算价。找不到记录表示资料不完整，不表示免费或没库存。

新配置的 SKU 为什么是空的？

从模板新建时不会沿用原商品的 SKU。到平台核对真实 SKU，再使用“粘贴 SPU / SKU”填写；缺失时相关复制会提示补齐。

同步出现冲突，应该点哪一个？

进入“处理冲突”，逐项查看原来的值、你的修改和云端修改。确认要保留的内容后，再选择采用本机或云端修改；看不出谁正确时先找修改人核对。

导出图片被挡住、挤在一起或提示超出怎么办？

先看右侧预览。调整字号、文字宽度、位置或显示内容；自由编辑后可用“恢复自动排版”重排。确认长图和方图各自正常，再重新导出；检查 ZIP 中的失败清单。

改错或删错了，怎么找回来？

刚改错先点“撤销”，撤销过头用“重做”。配置、模板、图库到各自的已删除列表或回收站恢复。需要回到较早状态时查看“同步 → 历史版本”，先看差异再还原。

保存失败，窗口关不掉怎么办？

先按提示处理保存错误，再保存。如果仍失败，关闭窗口时可选择保存恢复草稿后退出；草稿放在程序目录的 data/recovery。保留这个文件，再请维护人员协助恢复。

ERP 同步和多人同步，是不是一回事？

不是。ERP 同步负责把公司的成本和库存读到本机；多人同步负责共享配置、模板、人工核算价等工作资料。两者分别操作。

做到哪一步，才算完成？

工作台里完成这些

  • 配置、成本、文案核对好，状态显示已保存。
  • 图片下载成功，并打开检查内容和导出结果。
  • 维护表内容复制好，顺序、行数和编号对应。
  • 要交给同事时，完成同步并处理冲突。

这些仍需要另做

  • 把图片上传到抖店，替换商品详情和 SKU 图。
  • 在电商平台完成商品发布、售价修改。
  • 把复制内容粘贴到维护表，并核对公式结果。
  • 把监控 CSV 导入库存监控工具，确认启用。

重复配置越多，省时越明显

举例：一次维护 20 套配置，同时改配件、更新图片、整理维护表，估计可省 1～3 小时。前提是模板、商品编号和基础资料齐全。

预计节省 10～30 小时 / 月

这是工作量估算，不是实测承诺；不含平台上传、补资料和等待确认。同一批工作的出图时间已包含在内，不重复相加。
