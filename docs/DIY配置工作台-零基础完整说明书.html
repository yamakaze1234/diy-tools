v1.0.36 · 当前版本使用要点

链接卡片的“⋯”可编辑链接、改分类、配色或删除该链接全部配置。商品链接标题右侧的“⋯”提供删除所选、已删除配置和全部折叠。

主机模板单独分区，点击后展开，可新增或编辑。新建独立配置不继承已勾选链接和机箱图；复制配置紧跟原配置。展示配件可拖动排序。

批量样式新增“同步版本”，默认不勾选。勾选后采用当前版本名称；空版本会清空目标版本。只修改版本时，取消其他选项。

质保开关和配置图质保行已移除，空白模板不带质保。桌面版单张导出 PNG，多张导出到文件夹；网页版多张仍为 ZIP。

利润检测排除主机模板，只展示异常，按成本缺失、利润异常分类，可直接定位。库存与模板列表默认折叠。

保存流程已减少重复数据和日志计算。保存失败时先保留草稿，不要直接刷新；真实字段冲突仍需比较处理。

第一次操作：修改一套，导出一张图

准备好成员账号，以及一套允许你修改的配置。账号或程序没有准备好，先看打开工具并登录。下面一次只做一步。

  1. 在左上角选择店铺。检查：店铺名称是今天要处理的那家店。
  2. 在左侧搜索配置名称或型号，点开具体配置。检查：中间商品名、配置名都正确。
  3. 练习时先打开“更多操作”，点“复制一份配置”。选中复制出来的一套，把名称改成“练习配置”。完成后可从“更多操作 → 删除当前配置”清理练习副本；团队共享前先处理好。
  4. 点中间“展示配件”，找到要换的配件行。例如换内存：点击这一行的配件名称栏，输入型号或 ERP ID，在下拉结果中选中正确商品，再填数量。
  5. 点“实际配置”，再看一遍型号和数量。检查：这里记录真正要装的配件。展示页换配件会同步对应实际项；实际页单独修改后，要另看图片是否一致。
  6. 核对到手价，再点“成本核算”。检查：缺少单价时先补齐，不把暂时显示的利润当成最终结果。
  7. 看右侧图片，从上到下读一遍。检查：标题、型号、数量、升级文案正确；文字完整，图片不挡字。
  8. 点最上方“保存到本机”，等待保存完成。检查：顶部没有未保存或保存失败提示。
  9. 右侧打开“图片设置”，选“紧凑详情图”，点“导出当前图片”。选一个你找得到的文件夹。打开导出的 PNG，确认内容完整。

完成了：你已经会找配置、换配件、保存和导出。正式资料要给新用户看时，再点“同步 → 立即同步”，检查本轮同步结果。

新用户首次使用与当前操作速查

新用户首次使用步骤 · 当前版本

1. 将整个 ZIP 解压到固定、可写的文件夹，不要在压缩包内直接运行。

2. 双击 DIY配置工作台-v1.0.36.exe。EXE 与 _internal 文件夹必须放在一起。

3. 支持 Windows 10/11 64 位，不需要安装 Python 或 Node。

4. 若提示缺少 WebView2，运行包内 MicrosoftEdgeWebview2Setup.exe（安装时需联网）。

5. 使用已开通工作区权限的成员账号登录。新用户专用包已配置团队登录，但不包含任何人的账号密码、业务数据或登录缓存。

6. 等待首次同步完成，确认左上角店铺正确；没有资料时先检查同步状态和工作区权限。

7. ERP 连接需要在每台电脑单独设置；ERP 成本和库存仅本机使用，人工核算价参与团队共享。

日常顺序 · 当前版本

选店铺 → 新建或选择链接/配置 → 选择展示配件 → 核对实际配置、成本和售价 → 检查图片 → 保存到本机 → 导出；需共享时再执行同步。

点击配置名称决定当前编辑对象；左侧勾选决定批量操作范围，两者不同。

普通编辑自动保存，也可以点「保存到本机」。以保存成功提示为准。

链接、模板和配件 · 当前版本

商品链接右侧「⋯」：删除所选、已删除配置、全部折叠。

每张链接卡片「⋯」：编辑链接、修改分类、卡片配色、恢复默认配色、删除该链接全部配置。

误删配置可在「已删除配置」中恢复；当前恢复期限为删除后 3 天。

主机模板与日常配置分区，点击主机模板区域再展开，可新增或编辑模板。

新建独立配置不会沿用勾选链接或旧机箱图片；复制配置排在原配置后面。

展示配件通过拖动调整顺序；图片是否显示配件不等于实际用料是否存在。

质保开关和配置图质保行已移除，空白模板不带质保字段。

输出源维护 · 当前版本

左侧「工具与资料 → 输出源维护」。普通配件输入准确 ERP ID，读取产品名称和价格。

产品显示名称默认使用 ERP 名称，可以自行修改；修改名称不等于更换 ERP 商品。

新增时店铺选择默认为三个店铺全选，确认实际需要同步的店铺。

特殊配件使用特殊配件设置；WPS 导入后仍须核对识别结果、数量和成本。

维护输出源后，预览已有配置差异再同步；可按加购选项查看，并批量保留原描述。

批量处理 · 当前版本

先核对左侧已选数量，再打开「批量修改与维护表」。

「批量修改配色与格式」可同步配色、编辑格式、机箱图片、加购、福利和版本。

「同步版本」默认不勾选；勾选后采用当前配置的版本名称，当前为空则清空目标版本。

仅想修改版本时，先取消其他不需要的选项。应用前再次确认所选范围。

批量修改配件与批量修改加购描述是不同操作，按预览结果确认修改范围。

检查与导出 · 当前版本

利润检测不包含主机模板，仅显示异常，分为「成本缺失」「利润异常」，可直接定位配置。

库存检查可展开相关项并定位；未知库存不代表无库存。

主界面导出一张为 PNG，桌面版批量导图到所选文件夹；网页版批量导图为 ZIP。输出源差异同步的附带导图目前仍为 ZIP。

导出后打开图片检查型号、价格、版本和排版。导出不会自动上传到销售平台。

保存、同步与故障 · 当前版本

本机保存与云端同步是两步。需要新用户马上收到修改时，保存后点顶部「同步 → 立即同步」。

默认自动同步间隔为两小时；关闭程序期间不执行。

保存失败时不要立即刷新或强制退出，先保留当前输入并记录错误提示。

若关闭时提示将草稿保存到本机恢复文件，请选「是」；保留程序 data/recovery 中的草稿，交维护者核对恢复。

发生保存冲突时，可下载当前草稿，再重新比较；不要不看差异就覆盖。

v1.0.36 已优化大工作区保存时的内存使用，真实字段冲突仍会提示。

备份与升级 · 当前版本

数据在程序同级 data 文件夹。正常退出后备份整个程序文件夹，至少保留完整 data。

升级前先备份，由维护者迁移数据；不要把新用户包覆盖到正在运行的程序上。

不要只移动 EXE、只复制快捷方式或删除 _internal、data 文件夹。

新用户分发请使用标注「组内新用户使用」的包，不要复制自己的 data、登录缓存或 SQL 凭据给新用户。

最常用的三条操作顺序

配置与图片

返回当前配置快速回到正在编辑的配置位置。

去哪里点
左侧「工具与资料 → 返回当前配置」

作用范围：定位入口，不修改配置内容。

照着做

  1. 先看左侧“正在编辑”卡片，确认当前店铺、链接和配置名称。点击配置名称与勾选复选框是两种操作：前者决定编辑谁，后者用于批量选择。
  2. 在左侧展开“工具与资料”，点击“返回当前配置”，回到配置列表所在位置。
  3. 继续操作前核对中间编辑区的配置名称；需要换一套配置时，在左侧点击那套配置的名称。

完成后怎么核对
继续编辑原来的配置，已有批量勾选不会因此清空。

举个例子

查完资料想接着修改配置 3，可以从这里返回；不是新建一套配置。

这一点要分清
它是定位入口，不执行保存、撤销或云端同步，也不负责重置搜索条件。

配置模板从本店模板中挑选配置，添加到当前商品链接。

去哪里点
左侧「工具与资料 → 配置模板」

作用范围：当前店铺的模板库 → 当前链接；模板不跨店混用。

照着做

  1. 先选对店铺，再点击需要接收配置的商品链接。若还没有链接，先新建链接；不要只勾选一个链接就认为它是导入目标。
  2. 打开“工具与资料 → 配置模板”。先核对顶部“当前店铺”和“添加到”的链接名称；若提示统一本链接分期设置，先完成链接设置。
  3. 模板组默认收起。搜索模板或配置名称，点“展开”查看；可勾选组标题旁的复选框整组选中，也可只勾选组内几套配置。
  4. 确认底部“已选 N 套”，点击“添加所选配置”，等待添加并保存完成。
  5. 打开新配置逐一检查：配件、数量、售价、版本和图片是否符合本次商品；导入使用目标链接的 SPU，SKU 留空，需要补齐真实 SKU。
  6. 要建立可反复使用的模板，可在当前链接的“更多”中“整组存为模板”；要维护主机模板，可展开左侧“主机模板”区域新增或编辑。模板列表的删除项可在“已删除模板”中恢复。

完成后怎么核对
所选配置作为新副本加入目标链接。以后修改这份副本，不应当当作已经修改了模板库。

举个例子

新链接需要 14600KF 和 14700KF 两套配置：展开对应模板，只选这两套再添加，不必导入整组。配置简称用于快速识别，例如 14600KF+无卡+32G+1T丨进阶版。

这一点要分清
“配置模板”用于调用模板，“主机模板”区域用于维护模板。想从空白开始时使用“新建独立配置”，并核对创建后的所属链接；无需借用模板再逐项删除旧图片。

机箱图库先整理素材，再在配置中选用图片。

去哪里点
左侧「工具与资料 → 机箱图库」

作用范围：图库三店共用；更换图片时作用于当前配置。

照着做

  1. 打开“工具与资料 → 机箱图库”，用品牌、型号、颜色、版本或图片名称搜索，也可以沿左侧分类查找。
  2. 新增素材：点“＋ 新增图片”，选择 PNG/JPG（最大 24 MB），填写图片名称、品牌、型号、颜色、版本，再点“保存图片”。没有版本区分可填“通用”。
  3. 点图片查看大图、分类及“几套配置使用”。选“编辑资料”可修改图片名称和分类；保存后从新分类查找。
  4. 要用于配置，先回到该配置，再从右侧“更换机箱图”的图库选图入口进入，选择“使用图片”。更换主机箱图会保留该配置原来的图片位置和大小。
  5. 若要保留原图再加一张，使用图片编辑中的添加图片入口，从图库添加独立图片，再调整位置与大小。
  6. 不用的素材可“删除图片 → 确认移入回收站”；恢复时在图库“回收站”选择“恢复图片”。

完成后怎么核对
图库里能按分类找到素材；选图后在右侧预览检查机箱颜色、完整外形、位置和大小。

举个例子

同型号有黑、白两色：分别填写颜色并使用清楚的图片名称；换白色配置时选白图，而不是只改文字。

这一点要分清
直接从“工具与资料”进入是管理图库，不会仅因点击缩略图就替换配置图片。图库删除会保留已有配置和模板的原图引用。

批量维护

批量修改配件 / 加购 / 导图一次替换多条链接中的同一配件，或只修改逐项升级说明。

去哪里点
左侧「工具与资料 → 批量修改配件 / 加购 / 导图」

作用范围：本店日常配置；在弹窗内选链接、看预览，不仅看主界面勾选。

照着做

  1. 打开此入口，弹窗标题为“批量修改配件与导图”。先确认店铺，搜索原配件名称、ERP ID、链接或 SPU；需要时用配件类别缩小范围。
  2. 选择原配件后核对匹配链接和套数。匹配链接可能已经全部勾选，请取消本次不需要改的链接。主机模板不参与这个日常配置批量入口。
  3. 搜索并选中替换配件，核对准确 ERP ID。“统一数量”留空表示保留每套原数量；填正整数则统一为该数量。
  4. 点击“预览修改”，检查原配件→新配件、数量、涉及链接与配置。显示配件和对应实际配置会受影响；逐项升级说明是否变化，以预览后的配置为准，不要把它等同于人工加购整组同步。

输出源维护建立配件资料，并决定哪些旧配置跟随更新。

去哪里点
左侧「工具与资料 → 输出源维护」

作用范围：资料按店铺维护；新增可选三个店铺，更新旧配置需另做差异同步。

照着做

  1. 打开“工具与资料 → 输出源维护”，确认当前店铺。搜索配件名称或 ERP ID，编辑已有资料，或新增配件。
  2. 新增普通配件时填写准确 ERP ID，读取 ERP 产品名称与单价。产品显示名称默认使用 ERP 名称，可基于它修改；检查 ID 和实时查询结果是否对应正确商品。查询失败、无价格时先处理数据来源，不要把未知当作 0 元。
  3. 检查新增时的店铺勾选：默认三个店铺全选。只需部分店铺时取消对应选项；保存前确认最终范围。特殊项目使用“特殊配件”设置，不能把它当成已绑定普通 ERP 商品。

  8. 确认差异与数量后点“同步所选差异配置”。这里是把已保存输出源应用到本店配置；需要其他电脑收到时，还要执行顶部云端同步。
  9. 若同时选择生成图片，本入口目前导出 ZIP，内含配置图、SKU 图及“导出结果.json”。先核对成功/失败数量；必要时“重新保存并导出”。若只要文件夹出图，可先仅同步数据，再从主界面的图片导出入口导出。

完成后怎么核对

举个例子

把散热升级说明统一改成新文案，但保留某链接已有手写说明：只选“逐项升级说明”，预览后按链接保留该链接原描述，再应用其余差异。

这一点要分清
维护表的“加购描述”在这里对应配件的逐项升级说明，不会新增或重写人工“加购与选配”的商品组合、价格和数量。只改某一张图的名称，可直接在该配置的“展示名称”改，不必改全店资料。

三店共用成本价维护同一 ERP 商品的人工含税核算单价。

去哪里点
左侧「工具与资料 → 三店共用成本价」

作用范围：按 goods_id 在三店共用；会更新引用配置的核算成本。

照着做

  1. 打开“工具与资料 → 三店共用成本价”，弹窗标题为“成本源维护”。搜索 goods_id（即 ERP 商品 ID）或名称，先核对型号。

举个例子

内存单根含税价从 300 改为 320 元，一套实际使用 2 根的配置，其该项核算成本从 600 变成 640 元。

这一点要分清
ERP 成本与人工含税价是两种口径。不要因为两列不同就直接覆盖；更改本表也不是修改 ERP 系统价格。

检查商品库存找出本店配置里的无库存、低库存和未知库存配件。

去哪里点
左侧「工具与资料 → 检查商品库存」

作用范围：读取本机最近一次 ERP 库存；替换配件须另选范围并确认。

照着做

  1. 需要最新数据时，先点顶部“ERP 同步”，确认完成并查看库存时间，再进入“工具与资料 → 检查商品库存”。
  2. 核对当前店铺和“低库存阈值（≤）”。首次默认 5，之后可能保留上次设置；例如设 5，表示库存小于等于 5 时关注。改阈值后点“重新检查”。
  3. 先看统计，再按配件卡片查看“无库存”“低库存”和单独收起的“库存未知”。主机模板不参与；特殊配件跳过，图片中隐藏的普通配件仍检查。
  4. 卡片默认收起，可搜索配件、ERP ID 或关联链接。展开后点“定位配置”，查看该配件实际出现在哪一套、哪个位置以及数量。
  5. 要换缺货件，点对应卡片“勾选链接并替换”，在弹窗内勾选需要改的链接，选择新配件，再预览。检查实际配置和加购原/新内容，不要只看新配件名称。
  6. 确认预览后再应用。若选了导图，核对所选链接全部配置的导出范围；修改后重新检查库存并检查整机成本。

完成后怎么核对
得到基于本机库存快照的异常列表；确认替换后，对应配置中的用料才发生变化。

举个例子

某散热库存为 3、阈值为 5，列为低库存；另一配件显示未知，应先检查 ID 和 ERP 读取结果，不能按无库存处理。

这一点要分清
本功能检查和修改的是工作台配置，不会自动修改销售平台库存或上下架。ERP 同步之后仍要重新检查，旧报告不会变成实时库存。

一键检测利润批量发现成本缺失与利润异常，直接定位处理。

去哪里点
左侧「工具与资料 → 一键检测利润」

作用范围：本店日常配置，主机模板不参加；只展示异常结果。

照着做

  1. 先核对实际用料、数量、到手价和分期，保存当前编辑，再打开“工具与资料 → 一键检测利润”。
  2. 看清“已选 N 套”：左侧已有合格配置勾选时，默认采用这些配置；没有时默认选择本店全部合格配置。可搜索链接、SPU 或配置名称，按组选择；收起分组不等于取消勾选。
  3. 点“开始检测”，等待保存和 ERP 成本读取完成。ERP 连接失败或价格资料不全时，应按结果提示处理，不能视为检测通过。
  4. 检测后先处理“成本缺失”：用“定位配置”进入配置的成本区域，检查未绑定/未识别商品、缺少的人工含税价或 ERP 读取失败。补齐并保存后重新检测。
  5. 再看“利润异常”：区分“核算利润”和“ERP 利润”，核对到手价、分期、数量、单价及变化金额。当前规则分别提示亏损超过 300 元、累计变化绝对值超过 100 元的情况，不显示正常配置的长明细。
  6. “查看历史”用于对比历次检测。同一套配置可能同时存在成本缺失和另一口径利润异常，因此分类数量不一定能直接相加当作独立配置数。
  7. 确定一次成本或定价变化是业务认可的新起点后，才使用“重设此口径变化基准”。它只调整后续比较起点并保留历史，不会补成本、改售价或修复亏损。

完成后怎么核对
异常逐项定位、修正、重新检测；没有异常时仍核对本次检测套数与所选范围，确保该检查的配置都检查了。

举个例子

某套显示“成本缺失”，先补该配件单价再复检；有完整成本但利润偏低，则核对售价、分期和实际配件，不能靠重设基准解决亏损。

这一点要分清
ERP 与核算利润的有效性分别判断。首次没有历史比较值不等于涨跌为零。“发布到后台监控”是额外文件发布功能，只有需要接入既有监控流程时再配置。

照着做

做完后应该是这样：
得到符合用途的长图或正方形图片。同一店铺切换配置时保持统一视图，新增配置和重新打开后也沿用所选版式及 SKU 模式。

这一点要分清：
统一视图覆盖本店全部配置，不受左侧勾选范围限制；另一家店单独设置。它只统一版式和 SKU 模式，各配置的配件、配色及排版坐标仍分别保留。详情图和专用方图都要分别检查。

  4. 调整混乱时点击“恢复自动排版”；操作错了可用画布里的“撤销”。

价格和利润，分开看

“三店共用成本价”是人工维护的配件单价。“ERP 成本”从公司系统读取。两者来源和利润算法不同。

示例：到手价 5,000 元，店铺券 200 元

定价（标价）＝5,000 ＋ 200 ＝ 5,200 元。
选择 12 期：分期费＝5,000 × 6% ＝ 300 元。
选择 24 期：分期费＝5,000 × 10% ＝ 500 元。

假设人工含税成本合计 4,000 元，ERP 成本也为 4,000 元，选择 12 期：

EXCEL 利润＝5,000 − 4,000 − 5,000 × 4% − 100 − 300 ＝ 400 元。
ERP 利润＝5,000 × 98% − 4,000 ＝ 900 元（分期后实际 600 元）；不分期时不显示括号。

这是当前工作台的计算规则和假设金额，不是某套真实配置的收益。先确认所有实际配件的单价、数量、到手价和分期都完整，再看利润。

遇到问题，先看这里

找不到教程里说的按钮

先确认自己打开的是桌面版。左侧“工具与资料”、中间“更多操作”和“批量修改与维护表”、右侧“图片设置”和“排版工具”都需要先点开。旧版本的按钮名称可能不同。

我改了型号文字，为什么商品编号没变？

名称栏里的输入是搜索词，输入本身不会更换商品。请在下拉结果中选中准确商品，再核对 ERP ID 和实际配置；图片专用名称可在配件行下方的“展示名称”修改；默认名称在输出源维护中修改。

我隐藏了显卡，为什么成本还在？

“显示”只决定图片上是否出现。到“实际配置”检查真正使用的配件；确实没有该配件时，才移除对应实际用料。

新用户为什么看不到我的修改？

先确认你已保存到本机，再点顶部“同步 → 立即同步”。检查是否有错误或冲突。让新用户也同步一次，并确认查看的是同一店铺、商品和配置。

ERP 库存显示未知，是卖完了吗？

未知表示还没有可靠数据。先执行 ERP 同步，检查商品 ID 和读取结果。读取失败或没有匹配到商品，都不能按零库存判断。

改了输出源，旧配置为什么没变化？

输出源是配件资料库。保存资料后，还要预览已有配置的差异，确认更新。详见“输出源更新后，统一更新已有配置”。

图片的字太小、重叠或被截掉怎么办？

先看当前是详情图还是方图。打开“排版工具”调位置和字号；不会调整时用“恢复自动排版”，再检查整张图。补白方图字太小时可试“专用 SKU 排版”。

点了批量，怎么改到了其他配置？

勾选决定批量范围，点击名称决定当前编辑对象。这是两件事。操作前看已选数量和预览范围；筛选后也要检查之前是否还有勾选。

刚刚改错或删除了，怎么办？

刚改错先点中间“撤销”；画布改错用画布里的“撤销”。误删配置到左侧“商品链接右侧“⋯” → 已删除配置”恢复。更早的内容看历史版本，先查看差异再决定是否还原。

无法登录或读取 ERP，应该把什么告诉维护者？

记录你点击的按钮、发生时间和完整错误提示。登录问题说明成员账号；ERP 问题说明是否以前连接成功。密码不需要发给其他人。

换电脑时，只复制桌面快捷方式行不行？

快捷方式只是指向程序的位置。需要完整程序包；本机资料备份要在正常退出后复制程序同级的整个 data 文件夹。让维护者协助迁移，原电脑资料先保留。
