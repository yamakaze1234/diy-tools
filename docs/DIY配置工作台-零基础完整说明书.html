怎么导出图片 →

点配置名称＝打开这一套。勾选小方框＝把它加入批量操作范围。勾选了多套，并不表示你正在同时编辑它们。

第一次操作：修改一套，导出一张图

准备好成员账号，以及一套允许你修改的配置。账号或程序没有准备好，先看打开工具并登录。下面一次只做一步。

  1. 在左上角选择店铺。检查：店铺名称是今天要处理的那家店。
  2. 在左侧搜索配置名称或型号，点开具体配置。检查：中间商品名、配置名都正确。
  3. 练习时先打开“更多操作”，点“复制一份配置”。选中复制出来的一套，把名称改成“练习配置”。完成后可从“更多操作 → 删除当前配置”清理练习副本；团队共享前先处理好。
  4. 点中间“展示配件”，找到要换的配件行。例如换内存：点这一行的“选择配件”，搜索准确型号，选中正确商品，再填数量。
  5. 点“实际配置”，再看一遍型号和数量。检查：这里记录真正要装的配件。展示页换配件会同步对应实际项；实际页单独修改后，要另看图片是否一致。
  6. 核对到手价，再点“成本核算”。检查：缺少单价时先补齐，不把暂时显示的利润当成最终结果。
  7. 看右侧图片，从上到下读一遍。检查：标题、型号、数量、升级文案正确；文字完整，图片不挡字。
  8. 点最上方“保存到本机”，等待保存完成。检查：顶部没有未保存或保存失败提示。
  9. 右侧打开“图片设置”，选“紧凑详情图”，点“导出当前图片”。选一个你找得到的文件夹。打开导出的 PNG，确认内容完整。

完成了：你已经会找配置、换配件、保存和导出。正式资料要给同事看时，再点“同步 → 立即同步”，检查本轮同步结果。

编号从真实商品资料里复制，不需要自己编。

店铺

正在维护哪一家店。先选店铺，再改内容。

商品链接

一件商品的总入口，里面可放多套配置。

配置

一套主机的具体清单，例如 CPU、内存、硬盘各用什么、用几件。

配件

主机里的一个零件，例如一根内存。

SPU

商品链接的编号。一个链接通常对应多套配置。

SKU

具体销售规格的编号。不同配置应核对各自真实编号。

ERP ID / goodsId

公司系统里某件配件的准确编号。名称相似不代表编号相同。

输出源

常用配件的资料库，集中存名称、质保和加购等资料。

模板

事先存好的一套或一组配置，之后可以复制来用。

预览

正式应用前先看一遍将要发生的变化。

本机 / 云端

本机是你这台电脑；云端是团队共同收发资料的地方。

PNG / ZIP / CSV / JSON

PNG 是图片；ZIP 是装有多个文件的压缩包；CSV 是表格清单；JSON 是工具之间交换资料的文件。

用一个例子串起来

“某店铺”里有一个“白色主机”商品链接。链接下有“配置 1”和“配置 2”。每套配置有自己的 SKU；其中用到的内存，有对应的 ERP 配件编号。

配件、价格与成本

把基础资料维护好，图片和核算就有了依据。

选配件、改数量和展示名称装什么、装几件，在这里改。

去哪里点
中间「展示配件」或「实际配置」

照着做

  1. 在对应配件行点击“选择配件”，按名称或准确 ERP ID 搜索。
  2. 选中正确商品，再填写数量、检查名称及相关资料。
  3. 只想在图片里隐藏某配件，取消该行“配置图显示”。

做完后应该是这样：
实际配件清单、成本和配置图按编辑结果更新。

这一点要分清：
只改型号文字不会更换商品 ID，但展示项修改会同步对应实际项。换商品请使用“选择配件”；隐藏图片行也不会减掉成本。

维护人工核算价，查看整机利润一次填单件价格，按数量自动合计。

去哪里点
左侧「三店共用成本价」 / 中间「成本核算」

照着做

  1. 单条维护或批量粘贴商品 ID 与含税单价。
  2. 检查匹配结果、价格差异和异常行，再保存。
  3. 回到配置，核对数量、整机总成本及 EXCEL / ERP 两种利润。
  4. “缺少单价的行”应为 0。还有缺项时先补齐，再判断是否赚钱；EXCEL 利润与 ERP 利润的算法不同。

做完后应该是这样：
按“单价 × 数量”核算，引用这些配件的配置可更新成本。

这一点要分清：
人工核算价与 ERP 成本是两套数据。空值和未匹配资料不等于 0 元；#VALUE! 仅在能精确匹配 ERP 单价时提供替代。

改售价、优惠券和分期到手价、标价放在一起核对。

去哪里点
配置价格栏；左上「店铺设置」；商品区域「编辑链接」「配置总览」

照着做

  1. 填写配置到手价。优惠券到左上“店铺设置”修改；分期到商品区域“编辑链接”选择，同一链接全部配置统一使用。
  2. 查看标价和费用提示；当前规则：标价＝到手价＋店铺券，12/24 期费用按到手价的 6%/10% 计算。
  3. 要批量回填，进入总览的“从成本维护表更新价格”，粘贴简称、库存、定价三列并预览确认。

做完后应该是这样：
配置价格可统一维护，也可从总览复制定价列。

这一点要分清：
回填依据简称唯一匹配；库存列不代表平台库存已更新。这里只维护工作台价格，不会在平台自动改价。

读取 ERP 成本和可销库存从公司数据库读取最新资料。

去哪里点

  2. 读取后先看预览，核对商品 ID、单件成本和公司大库可销数。
  3. 确认应用，再回到配置检查成本及库存。

做完后应该是这样：
公司大库的“分库可销数”和 ERP 单件成本更新到这台电脑。

这一点要分清：
每台电脑各自读取；ERP 数据不随多人同步上传。读取不会覆盖人工核算价，也不会修改公司数据库。

设置升级、加购和福利把“加多少钱，换成什么”写清楚。

去哪里点
中间「升级与加购」 / 输出源的加购资料

照着做

  1. 只介绍升级内容时，填写升级说明、加购描述或福利文案，再看右侧图片。
  2. 加购商品编辑里可选“仅文字说明”，填写文案；这类内容不绑定商品，也不计算差价。
  3. 需要核算时，选择准确商品，分别填“原配件替换数量”“新配件数量”“此商品加购价”。可以添加多个加购商品，并选择是否展示。

恢复误改、误删的内容，减少重新录入。

这一点要分清：
会话撤销不是长期备份；重新打开后应依靠已删除列表、历史版本或备份恢复。

升级、换电脑和备份把工作资料一起带走。

去哪里点
程序所在文件夹中的 data 文件夹；顶部「同步」中的备份入口

照着做

  1. 完整备份时先正常退出工具，复制整个 data 文件夹，保留一份独立备份。
  2. 升级时保留原 data；移动工具时连同整个程序文件夹移动。
  3. 全新电脑用成员账号接收云端资料，再单独设置本机 ERP 连接；切换账号从“操作人”或同步窗口操作。

做完后应该是这样：
配置、素材及历史资料有可保留的副本，新电脑可以继续工作。

这一点要分清：
JSON 快照不等于包含所有图片和历史的完整备份。SQL 密码不会自动转移；原账号有未同步内容时，应先处理再换号。

第一次接收团队资料，或建立团队工作区普通同事通常只需要接收已有团队资料。

去哪里点
顶部「同步」→ 多人同步

照着做

  1. 已有团队：用维护者开通的账号登录；新空白工作台按提示接收云端数据。
  2. 本机已有内容：先核对内容，再使用“接收已有云端数据 → 备份本机并接收”。
  3. 只有负责首次建立工作区的人，才使用“预览并发布本机数据”，核对后“确认发布并启用同步”。
  4. 之后日常共享使用“立即同步”，并查看待同步和冲突状态。

做完后应该是这样：
本机加入正确的团队工作区。

这一点要分清：
接收已有数据会切换本机内容，不是日常刷新按钮。拿到公开空白程序但无法登录时，请维护者提供配置好的程序和成员账号。

出现同步冲突，逐项选要保留的内容两个人改了同一处，需要确定最终版本。

去哪里点
顶部「同步」→「处理冲突」

照着做

  1. 看清店铺、配置和发生冲突的字段。
  2. 比较“基础值”（两人修改前）、“我的修改”和“云端修改”。
  3. 确认后选“采用我的修改”或“采用云端修改”；不知道哪份正确时，向修改人核对具体字段。
  4. 处理后再次同步，打开配置检查最终内容。

做完后应该是这样：
冲突解决，团队可收到确定后的版本。

这一点要分清：
不要只看时间新旧。等待重试或提交尚未确认时保留本机数据，按错误提示处理网络或账号问题。

价格和利润，分开看

“三店共用成本价”是人工维护的配件单价。“ERP 成本”从公司系统读取。两者来源和利润算法不同。

示例：到手价 5,000 元，店铺券 200 元

定价（标价）＝5,000 ＋ 200 ＝ 5,200 元。
选择 12 期：分期费＝5,000 × 6% ＝ 300 元。
选择 24 期：分期费＝5,000 × 10% ＝ 500 元。

假设人工含税成本合计 4,000 元，ERP 成本也为 4,000 元，选择 12 期：

EXCEL 利润＝5,000 − 4,000 − 5,000 × 4% − 100 − 300 ＝ 400 元。
ERP 利润＝5,000 × 98% − 4,000 ＝ 900 元（分期后实际 600 元）；不分期时不显示括号。

这是当前工作台的计算规则和假设金额，不是某套真实配置的收益。先确认所有实际配件的单价、数量、到手价和分期都完整，再看利润。

遇到问题，先看这里

找不到教程里说的按钮

先确认自己打开的是桌面版。左侧“工具与资料”、中间“更多操作”和“批量修改与维护表”、右侧“图片设置”和“排版工具”都需要先点开。旧版本的按钮名称可能不同。

我改了型号文字，为什么商品编号没变？

型号文字是名称，商品编号是身份。要换成另一件商品，请点“选择配件”，选准确商品，然后核对实际配置。

我隐藏了显卡，为什么成本还在？

“显示”只决定图片上是否出现。到“实际配置”检查真正使用的配件；确实没有该配件时，才移除对应实际用料。

同事为什么看不到我的修改？

先确认你已保存到本机，再点顶部“同步 → 立即同步”。检查是否有错误或冲突。让同事也同步一次，并确认查看的是同一店铺、商品和配置。

ERP 库存显示未知，是卖完了吗？

未知表示还没有可靠数据。先执行 ERP 同步，检查商品 ID 和读取结果。读取失败或没有匹配到商品，都不能按零库存判断。

改了输出源，旧配置为什么没变化？

输出源是配件资料库。保存资料后，还要预览已有配置的差异，确认更新。详见“输出源更新后，统一更新已有配置”。

图片的字太小、重叠或被截掉怎么办？

先看当前是详情图还是方图。打开“排版工具”调位置和字号；不会调整时用“恢复自动排版”，再检查整张图。补白方图字太小时可试“专用 SKU 排版”。

点了批量，怎么改到了其他配置？

勾选决定批量范围，点击名称决定当前编辑对象。这是两件事。操作前看已选数量和预览范围；筛选后也要检查之前是否还有勾选。

刚刚改错或删除了，怎么办？

刚改错先点中间“撤销”；画布改错用画布里的“撤销”。误删配置到左侧“管理列表 → 已删除配置”恢复。更早的内容看历史版本，先查看差异再决定是否还原。

无法登录或读取 ERP，应该把什么告诉维护者？

记录你点击的按钮、发生时间和完整错误提示。登录问题说明成员账号；ERP 问题说明是否以前连接成功。密码不需要发给其他人。

换电脑时，只复制桌面快捷方式行不行？

快捷方式只是指向程序的位置。需要完整程序包；本机资料备份要在正常退出后复制程序同级的整个 data 文件夹。让维护者协助迁移，原电脑资料先保留。
