# 主机模板保存与接口核验（v1.0.35）

已修复：整组存为模板写入旧模板库，但侧栏只读取配置分类，导致保存后不可见。

保存的模板按店铺一次性归入正常配置编辑区，保留旧快照及迁移标记；新建、分类改入和整组保存均在侧栏可见。从模板添加读取最新编辑内容；删除及恢复共用配置流程。旧快照不会在删除后重新生成配置。

验证结果：
- 前端完整回归 335 项通过，追加模板同步往返测试通过。
- Python 后端 114 项通过，包含本地 HTTP、保存、鉴权、SQL 适配、同步队列与冲突等测试。
- 独立真实桌面窗口通过保存后定位、正常编辑、再次导入、两处删除恢复、重启保留和店铺隔离。
- 当前桌面入口可达 82 个模块，45 个完整接口地址均有后端处理；动态的登录/同步、SQL、缓存、版本和商品同步动作已展开核对。

接口核对属于源代码契约检查；模拟云端与 SQL 测试不等于真实 ERP、生产云端网络全量验收。
