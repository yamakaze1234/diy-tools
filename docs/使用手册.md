# 使用手册

适用版本：Python 桌面版 0.3.3。[返回首页](../README.md) · [部署与开发](部署与开发.md) · [架构说明](架构说明.md)

## 1. 选择安装方式

| 使用者 | 方式 | 前提 |
| --- | --- | --- |
| 日常业务成员 | 使用维护者提供的 Windows 分发 ZIP | 已开通成员账号，分发包已配置工作区 |
| 开发或自行部署 | 克隆源码、安装依赖并构建 | 自备 CloudBase 环境，按部署文档配置 |

GitHub 源码 ZIP 不是可直接运行的桌面安装包。打包程序从 [Releases](https://github.com/yamakaze1234/diy-tools/releases/latest) 下载，Git 源码中不含 EXE、真实配置或预设成员账号。公开分发包需要先按部署文档填写自己的云配置。

### 分发包启动

1. 正常退出旧版工作台，将分发 ZIP 完整解压到可写的固定目录。
2. 保持 `DIY配置工作台-Python-0.3.3.exe` 与 `_internal` 文件夹同级，双击 EXE。
3. 如提示缺少 WebView2，安装分发包内的 `MicrosoftEdgeWebview2Setup.exe`，完成后重新启动。引导安装程序需要联网。
4. 输入维护者开通的成员账号与密码。首次登录、重新验证身份和云同步需要连接云服务。

Windows 10/11 x64。分发包运行不需要用户另装 Python、Node 或 SQL 驱动。源码运行步骤见[部署与开发](部署与开发.md)。

## 2. 第一次进入工作区

登录前不显示业务内容。公开版初始数据为空，只有示例云配置；需先完成部署才能正常登录。

- **加入已有团队**：全新空白工作台可在登录后接收已发布的云端数据。若本机已有配置，进入“多人同步 → 接收已有云端数据”，核对提示，再点“备份本机并接收”。该操作先备份本机，完整下载后切换到云端内容。
- **首次建立共享基线**：由负责初始化的成员准备数据，打开“多人同步 → 预览并发布本机数据”。核对配置、模板、人工核算价、输出源与图库数量，处理预览问题，再点“确认发布并启用同步”。
- **日常进入已有工作区**：登录并不表示马上同步所有修改。普通编辑先落本机，需要共享时点“立即同步”。

不要将“接收已有云端数据”作为普通刷新按钮；它用于工作区初始化或接收流程。

## 3. 日常工作顺序

1. 登录后选择店铺、商品和配置，确认编辑对象。
2. 新建配置或使用模板，维护配件、数量、售价、人工核算价、升级项与服务说明。
3. 需要最新 ERP 成本和可销数时，执行 ERP 读取，检查差异后应用。
4. 调整配置图，检查预览，点击“保存配置”，再导出 PNG 或 ZIP。
5. 需要其他成员看到本次修改时，进入“多人同步 → 立即同步”，确认待提交和冲突状态。
6. 正常关闭窗口。程序会等待当前编辑保存；保存失败时处理提示后再关闭。

### 配置、配件与导入

界面支持配件搜索、模板、批量内容修改和批量外观设置。操作前核对选择范围；导入或批量操作以界面预览为准。

商品 ID 是 ERP 匹配依据。缺失或无效 ID 应先纠正，名称相似不表示同一商品。没有匹配到成本时，不要用另一件商品的成本填补。库存导出也需要真实、准确的商品 ID。

“配置图显示”控制海报是否显示某项配件，不等于从配置中删除该配件；隐藏项仍可存在于成本与维护数据中。

### 配置图与图库

- 选择店铺主题，调整文字、颜色、间距和模块显示。
- 更换机箱图时可从已有图库搜索并选择；切换图片与调整图片位置、大小是不同操作。
- 图片图层可拖动和缩放；调整后检查是否遮挡文字或超出画布。
- 普通编辑先保存配置，停止编辑并完成保存约三秒后再生成 PNG；“保存配置”可立即生成图片。
- 导出 PNG/ZIP 时选择保存位置并检查成品。导出文件保存在本机，不代表已上传到团队工作区。

## 4. ERP 成本与库存

打开顶部“连接设置”或“ERP同步”中的 SQL 连接界面，填写服务器、端口、数据库、用户名、密码和加密选项。连接地址和权限由数据库管理员提供。

1. 读取数据并进入预览。
2. 核对商品 ID、差异条数、库存及成本含义。
3. 确认后应用，检查目标配置中的结果。
4. 如需下次自动填入，可勾选“在本机加密保存并自动填入”。

| 字段 | 当前含义 |
| --- | --- |
| 库房 | 公司大库 |
| 可销数 | 公司大库的“分库可销数” |
| ERP 成本 | SQL“库存成本”，当前适配按单件成本处理 |
| 商品匹配 | 精确商品 ID |
| 人工核算价 | 人工维护的共享业务字段，与本机 ERP 成本分开 |

代码适配了特定 SQL 视图，其他 ERP 数据库需要先核对表结构和字段；不能只更换连接地址就假定兼容。查询细节见[部署与开发](部署与开发.md)。

每台电脑分别读取 ERP。连接凭据按 Windows 用户及工作台成员加密保存，不通过业务云同步分发；换电脑后重新填写。

## 5. 多人同步

普通编辑不实时上传。默认自动同步间隔为两小时；点击“立即同步”可随时执行，之后重新计算两小时。暂停自动同步仍允许手动同步。程序关闭期间不运行后台同步。

| 状态 | 含义与操作 |
| --- | --- |
| 尚未启用 | 尚未完成首次发布或接收 |
| 待同步 N 项 | 本机有待上传修改，可点立即同步 |
| 同步中 / 云端下载 | 等待本轮完成，可继续编辑 |
| N 项冲突 | 打开“处理冲突”查看字段差异 |
| 等待重试 | 检查具体错误和网络，保留本机数据 |
| 已同步 | 本机最近一轮同步已完成；其他成员此后仍可能继续修改 |

同步内容包括配置、人工核算价、店铺设置、模板、输出源和机箱图库。本机 ERP 成本、可销数、SQL 凭据、生成图和 ZIP 不作为共享业务字段同步。同步原始图片与导出海报是两条不同路径。

### 冲突处理

进入“多人同步 → 处理冲突”，展开查看基础值、我的修改和云端修改，确认后选择“采用我的修改”或“采用云端修改”。处理后再次同步并检查结果。不要仅按两台电脑的时间判断哪一份应该覆盖。

网络超时可能导致提交结果暂未确认。程序保留原提交 ID 以便核对，不要通过清空数据库或反复导入相同数据处理。

### 修改与提交记录

“多人同步 → 修改与提交记录”提供：

- 本机修改记录：保存操作的成员、本机时间及修改前后内容，从该功能启用后开始记录。
- 本机 / 云端差异：只读比较基准、本机与云端，不执行提交或推进同步游标。
- 云端提交记录：服务器时间、成员 ID、版本及提交编号。一轮同步可以包含多条记录。

### 退出与换账号

从“多人同步”退出或切换账号，本机数据保留。若提示还有原账号的未同步草稿、冲突或未确认提交，先用原账号完成处理，再切换；不同工作区不会自动合并。

## 6. 历史版本、备份与恢复

“多人同步 → 历史版本”可查看最近 100 个本机工作台版本。选择“查看差异”，核对后点击“备份当前并还原”。还原生成新版本，其共享字段会进入后续云同步，因此会影响团队内容。

完整备份与换电脑操作见[维护与排错](维护与排错.md)。界面的“下载同步备份”是同步层 JSON 快照，不等于包含全部图片、历史数据库与凭据的完整 `data` 备份；当前界面没有通用的一键导入该 JSON 入口。
