# 便捷操作追加方案

在已完成的 v1.0.23rc1 保存优化基础上追加，继续只交付独立候选，不安装、不修改当前程序及快捷方式。

## 输出源差异查看与批量保留

默认按“字段、原文、新文”合并相同差异，优先展示逐项升级说明。相同原文到相同新文只需审核一次；同一新选项但原文不同保持分组，避免隐藏不同加购内容。每组显示涉及链接、配置数量，展开后列出对应配置。

提供三层控制：已选链接全部保留原描述、整组选项保留、逐项保留。名称及升级描述可保留，核算单价仍按所选字段同步。支持按链接查看、全部展开/收起；查看方式切换不会重置选择，取消某链接后整组选项/全局操作不改变该链接已有选择。原有快照校验和默认保留已有升级文案继续保留。

验收包括分组合并与分开、三态勾选、未选链接隔离、空差异/仅税价、切换视图、实际提交结果、HTML转义，以及实际配置/人工加购不变。

## 独立主机模板区

现有数据同时存在 productCategory 为“主机模板”的普通配置及独立模板库。两者保留原存储与 ID，不自动迁移、删除或改写业务数据。

日常商品总列表、默认全选不包含主机模板分类。主机模板单独折叠，点击后才展开。分类模板继续通过现有完整配置编辑器维护；模板库提供普通表单新增和编辑，可改配置字段、配件、图片及模块文案，未编辑的外观字段保留。按店铺隔离，模板库编辑不生成隐含商品配置。

验收包括仅模板店铺、默认隐藏/全选、展开/收起、分类模板编辑、模板库新增与修改、刷新恢复、复制/套用仍可用、旧配置与其他店铺不变，以及保存异常时保留草稿。
