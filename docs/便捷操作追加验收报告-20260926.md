# 便捷操作追加验收报告

已完成 v1.0.23rc2 独立候选，承接 rc1 的保存优化、复制排序、独立新建和图片导出。本次没有安装新版，现用 v1.0.22 和桌面快捷方式未变。

## 已完成

- 主机模板不出现在日常商品总列表和默认全选中。左侧“主机模板”默认折叠，点击展开；切换店铺重新折叠。旧式主机模板继续在原有完整配置编辑器中修改，保留原记录和 ID。
- 模板区可直接新增、编辑模板库，维护配置、展示/实际配件、机箱图片、图片图层、加购和模块文案；保留未编辑的外观字段。模板库编辑不创建隐藏商品配置，不改已套用的商品配置。
- 日常批量配件、升级描述、样式、来源差异、默认主题与视图排除隐藏的旧式模板。打开旧式模板后，其主题和视图只改当前模板，批量样式限定当前模板链接。
- 输出源差异默认按相同加购选项的“原文 → 新文”分组，展示涉及链接和配置数量；不同原文不强行合并。可展开查看具体配置，也可切换按链接查看。
- 提供全局“一键保留原描述”、整组保留和单项保留；支持三态提示，切换视图不丢选择，未选链接不受批量保留影响。核算单价仍按所选字段同步。

共享 ERP 核算价维持原有契约：同 ERP ID 的业务配置共用成本，包括旧式主机模板；模板库不参与该成本写入。
