# 本地保存优化与新增需求验收报告

候选版本：**v1.0.23rc1**，2026-09-26。已完成方案、实施、独立审查、源码测试、实际窗口测试和打包验证。**未安装新版、未迁移当前数据、未修改桌面快捷方式**。旧版 v1.0.22 可继续使用。

## 性能结果

使用同一份不可变备份分别生成旧版、新版隔离副本，包含 716 条配置。所有测试禁止生产云端及 ERP 写入。

| 检查 | 旧版 | 候选版 | 降幅 |
|---|---:|---:|---:|
| 32 套批量保存后端耗时（三轮中位数） | 15.95 秒 | 2.65 秒 | 83.4% |
| 同批次请求大小 | 61.38 MiB | 0.75 MiB | 98.8% |
| 实窗点击“应用修改”至保存完成 | 20.95 秒 | 3.94 秒 | 81.2% |
| 32 套保存的规则调用次数 | 107 次 | 3 次 | — |

实窗样本选择同一条含 32 套配置的链接，其中 12 套命中相同配件规则；它与后端 32 套直接修改是两个独立样本，不能混用。实窗请求由 51,855,900 字节降到 294,261 字节。耗时为本机隔离样本，不承诺所有库规模及机器相同。

## 已完成内容

1. 保存差异复用，普通保存不重复执行同一轮全量差异计算。
2. 合并 Python 与嵌入规则引擎往返，批量只带目标配置及必要来源/成本上下文。
3. 新增增量批量接口，使用一个 SQLite 事务提交目标记录、恢复快照、审计及幂等回执；回执只带目标记录和活动增量。
4. 局部物化与商品文件增量更新；若前一轮派生文件失败，下一次保存会检测索引基线不一致并重建。
5. 图片按实际展示变化失效；只改实际配件时不再触发无关图片生成。

完整恢复快照和修改前历史仍保留；不能用跳过备份或冲突检测换速度。未选择的展示/实际清单受保护，保存期间继续输入与失败重试保留草稿。

## 追加需求

- 复制配置紧跟源配置插入；保存、重载与乱序同步投影后保留排序。
- 新建入口改为“新建独立配置”：先填写空白的新链接名称，创建独立归属。不会跟随勾选链接，也不会带入旧机箱图、图集、变换或自定义图层。明确复制及从模板导入继续保留原设计。
- 单张导出直接 PNG。
- 桌面多张导出选择保存文件夹，创建带时间的新子文件夹，写入编号 PNG 和导出清单；重复导出不覆盖旧文件，取消不写入。普通网页版保留 ZIP 兼容路径。
- 之前网页同步后编辑/删除冲突修复、WPS 特殊配件识别继续保留并回归。

## 验证证据

- JavaScript 全套 **329/329**，Python 全套 **105/105**。
- 原生 WebView2 实窗：只改实际、只改展示、同时修改三种范围；复制插入并重载；新建独立配置且不继承图片；网页同步后编辑及删除；WPS 三条特殊配件导入后直接得到零成本。
- 图片导出：单张 PNG 文件签名、多张网页版 ZIP 签名、桌面原生桥写入三张 PNG 和清单、取消、重复导出不覆盖、非法文件名及登录过期。
- 并发与恢复：相同字段冲突、独立字段合并、事务中途失败回滚、幂等回放、sidecar 失败后重启恢复、历史备份失败禁止业务提交、初次同步门槛、接收云端不上传本地草稿、纯本地切换同工作区成员。
- 候选 EXE：移除 PATH 中 Python/Node 后启动，登录/来源门槛、SQLite quick_check、夹具保留、88 个界面源码文件与打包内容一致；候选实际窗口启动、原生导出接口存在且未登录会拒绝。
- 独立审查发现均已修复并定向复验，最后的全量保存行为保持原契约。

系统文件夹选择器在自动化中用临时目录选择替身，原生桥接和文件写入真实执行。云端行为采用合成云/隔离验证，未执行生产账号登录、真实跨客户端云写入或 ERP 写入。候选配置与当前正式程序登录路由一致，但这不等于真实登录验收。

全套测试另修正了一处既有测试夹具：登录测试虚拟环境遗漏真实 login-config 模块。产品登录逻辑未因测试改动。新建测试仅允许启动时对缺失 sourceId 的配件按既有名称/ID 精确补齐，其他旧配置业务字段及图片均保持一致。
