# 维护、升级与故障排查

[返回首页](../README.md) · [使用手册](使用手册.md)

## 数据目录

| 场景 | 默认路径 |
| --- | --- |
| 源码运行 | `python-desktop/data/` |
| 打包程序 | EXE 同级 `data/` |
| 登录缓存与运行信息 | `data/runtime/` |
| 旧版迁移来源 | `%APPDATA%/DIYWorkbench/data/` |

只有目标 `data` 尚不存在且未指定自定义路径时，才尝试从旧 AppData 数据复制迁入；旧目录保留。已有目标目录不会自动合并或覆盖，即使目录为空。迁移结果记录在 `portable-migration.json`；Python 后台首次升级备份位置记录在 `python-backend-migration.json`。

## 完整备份

1. 等待本机保存完成并正常退出工作台。需要共享的内容先完成云同步。
2. 将整个 `data` 文件夹复制到带日期的备份目录，保留图片、SQLite 数据库、状态 JSON 与相关文件。
3. 核对文件数量、容量和关键文件，保存当前程序版本信息。

不要只复制 `state.json` 并当成完整备份。程序运行期间 SQLite 可能存在 WAL 文件；最容易复现的一致备份方式是正常关闭后复制整个目录。

## 升级

1. 退出旧程序并完成完整备份。
2. 将新分发包解压到新目录，保持 EXE 和 `_internal` 完整。
3. 将原 `data` 整体复制到新程序同级，再启动新程序。
4. 检查配置数量、图库、历史版本、成员和待同步状态。
5. 验收后保留旧目录用于回退，避免两版同时操作同一份数据。

程序不会自动把新数据改存回 AppData。遇到目录不可写，移动整个工具到可写路径，不要只移动 EXE。

## 换电脑与恢复

正常换电脑可使用全新分发包，登录团队成员并接收云端数据，再独立配置 SQL 连接。未同步草稿需要先在旧电脑完成同步，或保留完整本机备份进行受控迁移。

从完整备份恢复时，先关闭程序，将当前 `data` 改名留存，再将备份恢复为 `data`；启动后核对数据与同步状态。旧备份可能包含待提交操作，恢复后先检查再手动同步。换 Windows 用户或电脑后 SQL 加密凭据可能无法解密，需要重新填写；云端登录也可能需要重新验证。

“下载同步备份”的 JSON 不是上述完整备份，当前没有统一恢复按钮。历史版本还原则是业务操作，会生成新版本并进入共享字段同步。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 未配置 CloudBase / 无法登录 | 检查 `.env.local` 是否仍为示例，改完后重新构建 Web 资源；检查成员是否已加入工作区 |
| `NOT_MEMBER` | 管理员核对认证 UID 与 `wa_members` 中有效成员；只有认证账号不够 |
| `UPGRADE_REQUIRED` | 核对客户端协议 2 与数据库迁移版本 |
| 页面空白或缺少 WebView2 | 检查 WebView2 运行时、完整 `_internal` 及前端构建输出 |
| 提示另一个工作台运行 | 正常退出旧版；不要同时操作同一个数据目录 |
| 程序文件夹不可写 | 将整个工具放到当前用户有写权限的路径 |
| 修改后其他成员看不到 | 本机保存与云同步分开；双方检查立即同步、待提交和冲突状态 |
| 同步失败 / 提交待确认 | 保留本机数据，检查网络和云配置后重试；不要清空提交队列 |
| 无法切换账号 | 原账号存在未同步草稿、冲突或待确认请求时，先用原账号处理 |
| SQL 连接失败 | 检查地址、端口、网络、账号权限及加密设置，与数据库管理员核对 |
| SQL 字段缺失 / 重复 ID | 当前 ERP 视图不符合适配要求，先修正映射，不按名称猜测 |
| 库存或 ERP 成本不同 | 这些值保存在各电脑，需要各自重新读取 SQL |
| 图片未更新 | 等待本机保存和空闲生成，或点保存配置；检查导出是否选择了正确配置 |
| 关闭时提示未保存 | 保持窗口，处理保存错误后重新保存并关闭 |

## 反馈问题

提供程序版本、操作步骤、发生时间、完整错误提示与脱敏截图。开发者可用隔离数据目录和 `--headless --port 0` 观察启动输出。不要在公开 Issue 上传实际 `data`、连接密码、令牌或未脱敏业务备份。

## 升级时保留本机登录配置

公开发行包使用示例云配置。升级现有团队程序时，正常退出旧版，复制完整 `data` 后，还须将旧版 `_internal/web/.env.local` 复制到新版同一位置，并校验内容一致；此配置仅保留本机，不加入源码仓库或公开 ZIP。恢复草稿位于 `data/recovery`，复制后仍需按需恢复。源码预览的数据副本与正式程序数据分开保留。
