# DIY 配置工具功能介绍

以前制作和维护一套主机配置，需要在三个地方重复操作：

**WPS 写配置 → 导入 Canva 制作配置图 → 再把 WPS 配置整理到主机维护表。**

只要更换一个配件，WPS、Canva 图片和主机维护表都要分别修改、重新核对，工作量大，也容易出现名称、数量或 ERP ID 不一致。

现在，配置工具把这套流程集中到一个地方完成：

- 支持新建配置、复制配置、套用模板，也可以粘贴原来的 WPS 配置，方便旧数据转移。
- 配件栏可以直接搜索配件名称或 ERP ID，选择后自动带入对应信息。
- 配件名称统一在“输出源维护”中管理，修改后可以应用到相关配置，不需要逐个表格改名。
- 分开展示配置和实际配置：展示配置用于消费者看到的配置图，实际配置用于成本、利润、库存检查和主机维护表。
- 可直接预览配置图，调整主题、机箱图片、文字和排版，并导出单张或批量配置图、SKU 图。
- 可按主机维护表需要，整理并复制 ERP ID、配件数量、配置简称、定价等数据。
- 自动核算 ERP 成本、人工核算成本、利润和分期费用；成本缺失时会提示。
- 支持集中维护升级与加购，多个商品可以组合核算，并能一键检查升级差价。
- 支持按 ERP ID 检查配置库存，缺失或无法确认的库存会单独提示。
- 支持勾选多个商品链接或全选后批量换配件，同时处理对应加购文案。
- 支持本地保存、历史版本、恢复草稿和多人云同步。
- 三个店铺独立管理，每个店铺支持 8,000 套在用配置。

## 使用前后对比

**以前：**

WPS 写配置 → Canva 重新排版出图 → 手工搬到主机维护表 → 三处分别修改和核对。

**现在：**

工具内建立配置 → 搜索选择配件 → 核对成本、利润和库存 → 导出配置图 → 复制主机维护表数据。

## 主要价值

1. **减少重复录入**：一套配置同时用于图片、成本核算和维护表。
2. **降低错配风险**：通过 ERP ID 关联配件，减少同名、简称或手工复制造成的错误。
3. **提高出图效率**：修改配置后可以直接预览并重新导出图片。
4. **方便批量维护**：多链接可以一起换件、更新加购文案并导出变化后的图片。
5. **便于追溯和恢复**：保留历史版本、修改记录和恢复草稿。

## 目前仍需人工处理

- 主机维护表数据仍需复制并粘贴到原表。
- 库存和 ERP 成本需要先刷新，再根据最新数据核对。
- 特殊营销图片仍可使用 Canva 做进一步精修。
- 已经导出的图片和已经粘贴到外部表格的数据，不会自动跟随工具内的修改，需要重新导出或重新复制。

工具的核心不是单独替代 WPS 或 Canva，而是把配置数据集中维护，让配置图、成本核算和主机维护表尽量使用同一套准确的数据。
