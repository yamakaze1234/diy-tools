# 配置工具核心功能与旧流程对比

> 文档日期：2026 年 9 月 22 日  
> 对应桌面版本：1.0.2

## 一、工具的核心定位

将以前“WPS 写配置 → Canva 做配置图 → 再把 WPS 配置搬到主机维护表”的流程，整合为“维护一套配置，同时生成配置图和主机维护表所需数据”。

核心价值是减少重复录入，让配件、数量、图片、成本与维护表内容更容易保持一致。

## 二、新旧工作流程

### 以前的流程

1. 在 WPS 中填写配件名称、数量，整理不同配置版本。
2. 将 WPS 配置内容导入 Canva，调整文字、图片和排版。
3. 从 WPS 中整理配件 ERP ID、数量、简称和价格，再搬到主机维护表。
4. 配置发生变化后，分别检查和更新 WPS、Canva 配置图、主机维护表。

### 现在的流程

1. 在工具中选择店铺和商品链接，新建配置、复制现有配置、套用模板，或粘贴 WPS 配置（方便数据转移）。
2. 在配件名称栏直接搜索名称或 ERP ID，从下拉列表中选择配件。
3. 核对展示配件（店铺配置清单）、实际配置（导入到主机维护表的配置）、数量、升级加购和成本利润。
4. 在工具内预览和调整配置图，导出单张图片或批量图片。
5. 按主机维护表所需格式复制导出数据，再粘贴到原表。
6. 后续改配置时，以工具内的数据为基础，重新输出图片和维护表内容。

## 三、核心功能对比

| 工作环节 | 以前的方式 | 现在的工具 |
|---|---|---|
| 建立配置 | 在 WPS 中填写配件名称、数量，复制表格制作不同版本 | 按店铺、商品链接管理多套配置；支持直接创建、复制、模板导入和粘贴 WPS 配置 |
| 统一名称 | 多个表格中的同一配件需要分别改名 | 在本店输出源维护名称，再通过差异预览统一应用到相关配置 |
| 制作配置图 | 将 WPS 内容导入 Canva，再检查排版、图片和文字 | 配置直接生成预览；可调整主题、机箱图片、文字和布局，批量导出配置图 |
| 更换配件 | WPS、Canva 和维护表需要分别更新 | 替换展示配件后，同步该项到实际配置；图片和维护表输出使用对应数据 |
| 整理主机维护表 | 从 WPS 手工搬配件 ID、数量、简称和价格，容易串行或漏项 | 按维护表格式复制导出 ERP ID、数量、简称、定价等内容，再粘贴到原表 |
| 成本与利润 | 依靠表格公式、查价和人工核对 | 根据实际配置核算 ERP 成本、人工核算成本、利润及分期费用；缺少成本时给出提示|
| 升级与加购 | 文案、商品和差价分散维护 差价更新很难及时维护更新 | 集中维护升级加购，支持多个商品组合、新旧数量分别计算，并输出对应文案 支持一键检查升级差价 |
| 库存检查 | 另行查询库存，再人工对照配件 | 按配件 ERP ID 查看已获取的库存数据；未知或缺失数据单独提示 支持一键检查所有配置库存|
| 日常维护 | 多个文件、多份图片之间人工保持一致 | 支持本地保存、历史版本、恢复草稿和多人云同步 |
| 多店管理 | 分别维护不同店铺的表格和图片 | 三个店铺分别管理商品与配置，每店支持 8,000 套在用配置，已删除配置不占在用额度 |

## 四、展示配件与实际配置

工具将面向消费者的展示内容和内部核算清单分开管理。

| 类型 | 主要用途 | 修改关系 |
|---|---|---|
| 展示配件 | 用于消费者看到的配置图，可控制某项是否在图片中显示 | 选择配件或修改数量时，同步该项到实际配置 |
| 实际配置 | 用于成本、利润、库存检查和维护表输出 | 可以单独调整，不反向修改展示清单 |

配件名称栏用于搜索和选择，输入搜索词本身不会修改已选配件名称。需要修改输出名称时，在输出源维护中编辑。

## 五、实际使用示例

### 将 CPU 从 i5-14600K 换成 i5-14600KF

**以前：**

1. 在 WPS 中修改 CPU 名称和对应信息。
2. 更新 Canva 配置图中的文字，并重新导出图片。
3. 修改主机维护表中的 CPU ERP ID 和数量，重新核对成本。
4. 人工确认三处内容一致。

**现在：**
单链接：
1. 在批量修改处的 CPU 配件栏中搜索 i5-14600KF，并选择正确配件。
2. 核对同步后的实际配置、数量、成本和利润。
3. 检查配置图预览并重新导出。
4. 复制维护表所需数据，粘贴更新原表。
多链接：
1.勾选需要改的链接，支持全选
2.批量修改配件-查找替换-选择配件
3.一键批量修改配件及对应加购文案
4.可一键导出所有有变动的链接配置图和sku图


## 六、当前仍需要人工处理的部分

- 主机维护表仍需将工具导出的内容粘贴进去。
- 库存和 ERP 成本以最近一次成功获取的数据为准，需要按业务情况刷新和核对。
- 常规配置图可在工具内完成；特殊图片仍需使用 Canva 精修。
- 配置、人工核算价等支持云同步；ERP 成本和库存主要保留在本机。云同步不代表每次编辑都会立即上传。
- 已经导出的图片或已经粘贴到外部表格的数据，不会随工具内修改自动更新，需要重新输出。

## 七、对日常工作的主要帮助

1. **减少重复录入**：同一套配置不必在多个环节反复填写配件信息。
2. **降低错配概率**：通过 ERP ID 关联配件，减少只看名称造成的混淆。
3. **缩短出图流程**：配置与图片预览结合，修改后可以直接检查并导出。
4. **方便批量维护**：通过模板、输出源维护和批量导出处理多套配置。
5. **便于核算和追溯**：实际配置用于核算，并保留本地历史与恢复草稿。
