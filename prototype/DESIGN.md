# 原型设计与范围

面向 DIY 主机运营人员，核心任务是修改一份配置并得到一致的详情图与维护表复制内容。

配色：页面冰灰 #F4F7FB、面板白 #FFFFFF、正文深蓝 #132744、操作蓝 #0068E8、成功青绿 #12857B、分隔线 #E2E9F2。标题使用 Segoe UI Variable / 微软雅黑，正文使用 Microsoft YaHei UI，编号和金额使用 Consolas。三栏：商品配置导航 244px、可编辑工作区弹性宽、预览区 400px；窄屏改为上下布局。辨识点是始终可见的真实配置图，不做无业务意义的统计图。

设计复核：沿用用户认可的工作台结构、蓝白店铺模板和真实机箱素材；配件图案完全移除。长图默认，方图严格 1:1；正文自然换行并显示溢出提示。模板、加购、福利可编辑；已填写的配置与平台 ID 分开保存。

运行范围：仅绑定 127.0.0.1。本地 Node 服务保存配置及生成图片；无外部发布、无宏执行、无 ERP 实时采集、无多人认证。跨标签页保存采用版本冲突检查。原型不会修改来源 Excel、旧 HTML 工具或机箱图片。
