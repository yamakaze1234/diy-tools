# 成本源与库存 / ERP 同步

## 使用位置

日常工作台：http://127.0.0.1:4178/。左侧“成本源”维护含税核算单价；右上角“一键同步库存 / ERP”更新公司大库可销库存与 ERP 单件成本。

## 首次连接

1. 启动工作台，点击右上角“连接设置”，打开并安装 `workbench-erp.user.js`。已安装脚本猫等脚本管理器时可直接安装；若浏览器只显示源码，使用“复制脚本”，在脚本管理器中新建脚本、粘贴并保存。
2. 在 `https://cqzs.3cerp.com/` 已登录的页面，打开“分库库存”，选择“公司大库”，显示成本单价列。
3. 点击 ERP 页面右下角“工作台同步：点击连接”，输入顶栏实际显示的账号姓名，选择真实成本单价列。有多个成本列时按页面列名核对后选择。脚本不要求密码。
4. 保持 ERP 页面打开，回到工作台点击“一键同步库存 / ERP”。首次点击时若未连接，会先显示安装说明。

这是独立的工作台采集脚本。原后台库存监控项目的脚本、端口、配置和数据保持不变；两个脚本可以共存。工作台脚本连接本机 4178，ERP 页面需要与工作台运行在同一台电脑。

## 日常维护

- 成本源表格显示 goods_id、ERP 商品名称、可销库存、ERP 成本、含税核算单价和人工更新时间。按 ID 或名称搜索后可逐行修改并保存；价格为单件价。
- 批量粘贴支持 `goods_id + Tab + 含税单价` 两列；也可勾选商品或全选搜索结果后，粘贴单列价格，按成本源表格原始顺序对应。单列空行保留原价，0 是有效价格。先预览再保存。
- 从成本源保存后，按准确 goods_id 更新输出源和所有未删除的引用配置，保留数量、SPU、SKU、显示文案，重新计算利润并按现有流程保存图片。输出源界面仍保留其原有字段、范围和差异预览功能。
- 人工更新时间和 ERP 成功同步时间分别记录。再次保存相同人工价格也记录本次维护时间。
- ERP 同步只改库存和 ERP 成本，人工含税核算价及其时间不会被覆盖。源数据按完整分页检查，通过后一次性写入本地文件。
- ERP 新商品加入成本源，含税价留空待人工维护；不会直接新增配置或改写产品显示名称。

## 状态说明

“未同步”表示尚未采集库存；“未知”表示 ERP 返回空库存；“未匹配”表示本轮没有相应 ID。空 ERP 成本保留旧值并标注，不以 0 替代。未匹配记录也保留旧值。

采集失败、分页缺失、重复 ID、账号/仓库不符或超时会停止本轮更新，保留旧数据和上次成功时间。第一次成功会绑定账号与仓库；之后不允许其他账号混入。如需切换数据所属账号，需要单独调整绑定，当前界面没有自动切换入口。

成本字段从 ERP 实际表格的列定义识别，不预设未经核验的字段名；如果识别不到，请先显示成本单价列并重新连接。当前已验证工作台界面、完整分页逻辑和模拟采集回传，真实 ERP 浏览器暂未连接，实际成本列及现场采集仍待第一次连接验收。

## 保存与冲突

成本源、输出源及同步记录保存在 `.local/state.json`，包含在“备份数据”中。多个页面同时修改时按版本检查，冲突页面保留草稿并提示先备份再载入；不要在冲突状态直接恢复旧备份覆盖新数据。
