# DIY 配置工作台 · 可操作原型

## 2026-09-16 更新：机箱图库

左侧原“操作记录”位置改为“机箱图库”，操作记录移至右上角。图库三店共用，支持按品牌 → 型号 → 颜色 → 版本多级浏览，也可输入名称、型号、颜色等关键词搜索。

点击“新增图片”，选择 PNG/JPG（最大 24MB），填写图片名称、品牌、型号、颜色和版本后保存。例如：乔思伯 / X400CG / 白色 / 豪华。无版本区分时填写“通用”。点击图片可查看资料、编辑分类及查看使用配置数量。

右侧预览区的“更换机箱图”现在打开图库。搜索后点击“使用图片”，只更换当前配置的机箱图片，保留原位置、大小、显示开关和文字样式。现有配置和模板使用的本地机箱图会自动收录到“待分类”，可继续补分类。

“删除图片”经确认后移入图库回收站，原始文件保留，已有配置和模板不受影响。回收站支持恢复，删除状态刷新或重启后仍保留。

图库信息随本地数据和 JSON 备份保存；原始文件仍在本机素材目录，跨电脑迁移还需复制素材目录。此版本尚未接入 CloudBase。更新后需重启本地服务并刷新页面。

### 添加图片与重做

配置图预览右上角点击「添加图片」，可一次选择多张 PNG/JPG（单张小于 24MB）。图片作为独立图层添加，默认放在最上层，保留原图比例与透明背景。点击图片后直接拖动位置，拖动右下角方块或调整「图片宽度」滑杆等比例缩放，也可输入水平、垂直位置。方向键微移，按住 Shift 每次移动 10px。

图片重叠时，在预览下方「添加的图片」列表选择需要编辑的图片；可「置于顶层」或「移除图片」。移除只取消当前配置中的图片，不删除本地素材。详情图与方图分别保存位置和大小。添加的图片随配置自动保存，并包含在 PNG、已保存图片和批量 ZIP 中。

「撤销」旁新增「重做」，支持恢复已撤销的编辑，包括添加、移动、缩放和移除图片。撤销后进行新的修改会清空重做记录；刷新页面后编辑历史清空，已保存的配置和图片保留。

### 原位分类编辑与色板面板

点击左侧链接下方的分类标签，可在原位选择已有分类或输入新名称，保存即设置到该链接全部配置，留空为未分类。取消不修改，Enter 保存名称，Escape 取消。

所有颜色入口显示圆形色块和 HEX 色值，点击打开色板。面板包含当前设计颜色、收藏颜色和默认纯色；支持按颜色名称搜索、输入 3/6 位 HEX、自定义选色。点击色块直接应用；手动输入或自定义选色后点击「应用」。收藏保存在本机浏览器，与预览文字编辑器的颜色收藏共用。面板标题和搜索栏固定，颜色区域可滚动。

### 全部折叠与分类筛选

左侧「全部折叠」收起所有商品链接，搜索状态下同样有效，不改变正在编辑的配置或已勾选项。点击链接标题可单独展开；「定位」会清除搜索和分类筛选，返回当前配置。

新增或编辑商品链接时可设置「链接分类」，预置日常主推链接、24期主机专区、竖装主机专区、无卡主机专区，也可输入自定义分类；留空为未分类。分类随整个链接保存，同一链接新增空白配置或导入模板时沿用该链接分类。左侧下拉框按分类筛选，并可叠加关键词搜索。「全选」只勾选或取消当前筛选结果，其他范围已勾选的配置保持原样。

## 2026-09-16：商品链接导航

展开链接时，该链接移到列表顶部；在其配置范围内滚动时，链接标题吸顶。列表上方的「正在编辑」卡片始终显示当前链接和配置，浏览其他链接不会切换编辑对象。点击「定位」会清除搜索、展开当前链接并滚动到当前配置。当前链接有蓝色标记，当前配置有蓝色边线；长链接名称可换行。桌面总功能入口改为两列，为商品链接列表留出更多空间。

## 全局批量修改配件与打包导出

刷新工作台，在左侧总功能区点击「批量修改」。输入原配件名称或 ERP ID，选择候选配件，列出所有关联链接及命中配置。按准确 ERP ID 查找；无有效 ID 的配件按完整名称匹配，不按相似型号自动替换。

勾选要处理的链接，搜索并选择新配件，数量可留空保留或统一填写。先点击「预览统一修改」，核对后点击「应用修改」。替换带入新配件的名称、ID、成本、质保、升级及关联加购资料，保留原槽位和图片显示状态；只修改命中配件，配置价格、SPU/SKU 和未选链接保持原样。可使用工作台「撤销」恢复。

可勾选「修改后自动导出」：保存成功后，把所选链接的全部配置（包括该链接内未命中原配件的配置）分别生成 1400px 配置清单图和 1400×1400 的 SKU 图，下载为一个 ZIP。每个链接一个文件夹，内部按「配置清单图 / SKU图」分开，文件名为「SPU_配置编号.png」。普通配置名称沿用其配置编号，其他名称按链接内顺序编号。缺少 SPU 或编号重复时提示先修正，也可取消自动导出，仅修改配件。个别图片失败会在页面及 ZIP 的导出结果中列明；可修正后再次导出。

所有弹窗的标题和关闭按钮固定在顶部，内容单独滚动。配件搜索、成本源和输出源搜索栏滚动时保持可见；配置总览保留顶部复制操作和列标题。常规桌面左侧配置列表单独滚动，上方搜索与批量操作保留。

数量大于 1 时，配置图在型号末尾显示普通「×2」「×8」文字，与型号使用同一字体和颜色，不再使用独立强调框。配件文字上下居中；有升级说明或质保时，按整组文字排版。实际配件数量及成本计算不变。

## 2026-09-15 更新：配置图自适应排版

刷新工作台后自动生效。隐藏模块以及没有实际内容的加购、福利、服务承诺、自定义文字、页脚均不占位。配置图有剩余空间时，优先增加配件行的上下留白，并同步调整模块间距，减少页脚上方或底部的大块空白。模块顺序、手动字体样式和机箱素材尺寸保留；预览、下载和批量导出使用同一套排版。

方图仍为固定 1:1；详情图保留原有画布尺寸规则（1400 宽时基础高度 1834，内容过多时延长）。空模块不会为凑满画布添加占位文案。

## 2026-09-15 更新：WPS 配件导入与固定总览

刷新工作台即可使用，无需重启服务。

「新增配置链接」中展开「从 WPS 粘贴配置配件」，可一次粘贴多套配置，保留每套 19 行的原表结构，不需要手工删空行。支持 goods ID／数量／配件名称三列、D:H 五列，也支持从 A 列开始的完整表格。D:H 数量默认自动识别：F 列全空时使用 E 列；也可手动选 E/F。点击「预览导入配件」，按组核对名称、ID、数量和分类后，再点击「创建并编辑配置」，会在同一链接下分别创建所有配置。不粘贴时仍可创建空白配置。

长 ID 原样保存为文本。先保留原始行位置分组，再跳过每组表头、汇总行、空行及名称为空或 0 的配件占位行，并显示跳过数量。无卡行保留名称，不伪造 ID；未匹配本地成本的配件保留原 ID、名称并提示待补成本。不能识别的分类可在预览表中选择；非空配件的 ID、数量错误仍需修正。每组粘贴原文及其在原表中的起始行号随配置保存，便于核对。

「配置总览」现在只滚动配置列表，标题、关闭按钮、复制按钮和列标题固定显示。生成简称的按钮和操作记录统一显示「生成简称」。

## 打开

双击本目录的 `启动原型.cmd`，自动启动本地服务并打开 `http://127.0.0.1:4178/`。也可在本目录运行 `node server.mjs`。浏览器不能通过直接双击 index.html 使用此原型，因为配置与图片需要本地服务保存。

当前包含用户 XLSX 中 X400 白页的 20 套真实配置缓存、1,189 条配件目录及用户提供的透明机箱照片。未填写或伪造平台 SKU ID。原 Excel、宏维护表、原 HTML 工具和原机箱图片均不修改。

## 推荐试用流程

1. 左侧点击配置打开编辑；复选框决定批量修改、复制和导出的范围。点击配置与勾选配置是两个独立操作。
2. 在“配件配置”直接编辑展示名称、数量，或点击“选择配件”搜索目录。选用目录配件会同步其 ID 与样例单价。只改展示名不会更换原 ID。
3. 在“升级与加购”修改行内升级说明、底部加购和福利点。加购初始文案是设计示例，福利默认为空；实际未选购的加购不计入配置成本和 ERP 输出。
4. 在“模块与样式”调整标题、字体、字号、字重、颜色、间距和显示开关；拖动模块标题或点上下按钮调整顺序。可新增自定义文字模块。右侧预览可点击模块定位编辑。
5. 选择“紧凑详情图”或“1:1 固定方图”，再选择浅色或深色。详情图以 1:1.31 为常规比例，内容较多时自动增高；方图使用固定正方形画布。两者都采用通栏圆角配件行，类别、型号和右侧数量分别对齐，根据最长型号适配字号与换行，不补白边。内容超过可读范围时提示调整后再导出。机箱图保持真实比例。
6. 编辑后约 1 秒自动保存；也可点击“保存配置”。配置保存成功后自动生成当前样式的 1400px PNG，界面显示图片保存状态。下载 PNG 可选 1400 / 2800 / 4200px；批量导出将所有勾选配置按当前版式和主题生成 ZIP，内含图片与成功/失败清单。
7. “生成简称”支持两种既有规则，并启用自动更新。手工编辑简称后暂停自动覆盖；再次点击生成可恢复自动模式。
8. 维护表复制分别提供 SPU、SKU ID、简称及 56 列展开配件。所有区域采用相同配置顺序，不含表头。SKU ID 缺失会阻止复制；请先逐项输入或批量粘贴。SPU / SKU 的目标表列应设置为文本。表中有隐藏列，不将所有字段直接拼为一整行。
9. 点击“新增配置链接”创建商品组，可直接编辑首套空白配置，或点击“添加模板配置”勾选导入。每个链接可以折叠/展开。“整组存为模板”保存该链接的全部配置与样式；调用时支持整组选中或仅勾选部分配置。新配置采用目标链接的 SPU，SKU 留空，不继承来源模板的平台身份。旧单配置模板仍可使用。
10. 左侧“成本源”支持人工维护含税单价及批量粘贴，每次保存记录时间并更新引用配置。右上角“一键同步库存 / ERP”通过独立采集脚本更新公司大库可销库存、ERP 单件成本；首次使用请点击“连接设置”。详见 `ERP同步安装说明.md`。原“成本核算”的两列手工 ERP 导入仍可使用，仅影响当前配置。

## 链接、模板与到手价

- 配置标题旁的“查看配置总览”列出当前链接每套配置的 CPU、显卡、内存、硬盘与版本摘要，可复制摘要或点击跳转编辑。
- 模板卡片右侧可“删除”；弹窗内支持“撤销删除”，关闭或刷新后也可从“已删除模板”恢复。删除模板不会删除已经生成的配置。
- 到手价可直接在配件配置上方的价格栏编辑，成本与利润使用同一价格。配件名称输入框按内容自动增高。
- “编辑链接”可更新整组名称、网址与 SPU；网址仅作记录，不自动发布或改动电商平台商品。

## 删除配置与利润

- 左侧支持单套勾选、按商品链接全选以及顶部全选；点击“删除所选”批量删除。标题右侧“删除该配置”只删除当前打开的配置。
- 删除后从正常列表及批量复制/导出范围移除；可用“撤销”或“已删除配置”恢复，刷新后仍可恢复。全部删除后显示空白页，支持重新新建链接。模板和已保存图片文件保留。
- 到手价输入框固定为紧凑宽度，价格栏实时显示两项利润。来源为原表 `X400白3797170100491124774` 的 C2、D2、E2：EXCEL 利润 = 到手价 −（含税总成本 × 1.04 + 100）；ERP 利润 = 到手价 × 0.98 − ERP 总成本。成本先按各行单价 × 数量汇总，金额显示两位小数。

## 输出源维护

左侧“输出源维护”带入原表的 1,189 条配件，支持搜索、分页、新增配件和逐条编辑。

1. 按名称或准确 ERP ID 搜索配件，修改产品显示名称、含税核算单价、升级文案、加购项目和加购说明。核算价格为单件价；ERP 价格来自最近同步，首次同步前显示原表缓存。ERP 价格不在此处人工覆盖。
2. “仅保存输出源”只维护配件库。此后从“选择配件”或批量更换配件选用时，带入新资料。
3. 要更新现有配置，勾选需要同步的字段，选择全部引用配置、当前商品链接或左侧勾选配置，点击“预览同步差异”，再“保存并同步这些配置”。
4. 同步保留配件数量、ERP 成本和平台身份；只更新来源关联的加购项，手动加购保留。加购文案不计入成本。配置保存后图片按原保存流程更新；具体成功/失败状态见配置预览。
5. 更新记录保存在 `.local/state.json` 的 `sourceCatalog` 中，包含在“备份数据”中，也支持当前会话撤销。旧模板保持自身快照，不随输出源自动改动。

重复 ERP ID 通过具体来源记录区分；无法明确对应的旧配件不按模糊名称猜测。可以在配置里重新“选择配件”绑定正确来源。

## 数据与恢复

- 正式试用数据：`.local/state.json`；自动生成图片：`.local/images/`；上传素材：`.local/assets/`。
- “备份数据”下载 JSON；“恢复备份”先展示配置数量，再恢复，当前会话可撤销。迁移到其他电脑时，应连同 `.local/assets/` 和 `assets/` 复制，JSON 本身不内嵌图片。
- 跨标签页保存带版本检查。发生冲突时保留页面草稿，先下载备份再重新载入；不会静默覆盖另一个页面的已保存数据。
- 4179 是本次独立验证实例，数据保存在 `.verification/`；期间用户已试用，不自动清理。后续日常试用统一使用 4178。两个端口的数据相互独立。

## 原型边界

这是本机可操作原型，不是已上线的多人业务系统。尚未接入账号与店铺权限、外网部署、真实平台 SKU 自动采集或商品图片自动发布。ERP 采集入口和独立脚本已实现，须在用户 ERP 浏览器首次安装并连接；当前通过模拟回传验证，真实 ERP 现场采集尚未验收。ERP 横向格式已对比现有 V5 样例，但原宏维护表的实际粘贴和公式计算仍需用户本机验收，无需提供工作簿副本。

当前支持单项文字的字体、字号、字重、斜体与颜色，以及机箱图独立拖动和缩放；其他模块的自由定位、每个模块背景、模板跨店继承以及素材随 JSON 打包，可在后续迭代补齐。图片页列出本次会话生成记录；此前生成文件仍保存在 images 文件夹。

## 验证

`node --test tests/*.test.mjs`：V5 逐格复制兼容、真实成本核算、长 ID、数量映射、模板身份清空、简称规则、ZIP 结构、ERP 完整分页校验、空值处理和人工核算价保留。

`tests/render.html`：独立浏览器渲染样例，不写配置数据。`tests/render-node.mjs` 使用本机已有的原生 Canvas 包执行同一 poster.js，验证浅深主题和长/方图的完整性，输出在 `verification/`。当前验证入口见 `../README.md` 的测试与打包章节。

成本源批量粘贴可以保留 goods_id / 含税成本表头。预览会显示匹配、未匹配、空值保留和相同重复行数量；价格冲突时提示具体行号。大批量仅展示前 100 条差异，保存按钮上的数量代表本次全部应用条数。保存期间显示处理提示；升级页面前请先复制保留尚未保存的粘贴内容。

批量核算价出现 #VALUE! 时，按准确 goods_id 改用对应的 ERP 单价，预览会标明替换。ERP 成本为 0 可以使用；成本缺失、未知或本轮未匹配则保留原核算价并提示。普通价格即使等于 ERP 成本，也照常保存。点击保存后才应用并记录人工维护时间。


## 预览直接编辑与输出源删除

- 点击预览中的具体文字，在预览下方调整字体、字号、字重、斜体、颜色；选择“恢复模块样式”可清除该文字的单独设置。局部文字样式优先于模块默认样式。
- “放大编辑”打开大画布和侧边样式区；点击“收起编辑”或按 Esc 返回。编辑结果与侧栏使用同一份配置数据。
- 颜色区提供预选色，“保存当前颜色”保存到当前浏览器，跨配置可用，刷新仍保留；浏览器常用色不包含在 JSON 配置备份中。
- 拖动机箱图片移动，拖动右下角方块缩放，也可用滑块及位置数值调整。文字的位置、换行、其他模块不跟随移动。长图和方图分别保存图片位置，可一键重置。
- 输出源编辑区右下角“删除输出源”移除可选记录；“已删除”可恢复。已有配置、模板和成本源保留，删除期间不能从选配库重新选用该记录。
- 工作台面板、按钮、配件卡片、加购和福利区采用圆角。固定方图型号优先按完整英文规格换行，避免将 DDR4、6500Mb/s 等拆开。

## 通栏版式与服务承诺

方图固定 1:1，紧凑详情图常规比例为 1:1.31（1400 × 1834）；配件和附加文字超出常规高度时，详情图自动延长，不裁切内容。两种版式统一采用浅蓝/深蓝圆角通栏，按最长型号调整共同字号，特别长的型号自动换行，数量标签单独对齐右侧。

在「模块与样式 → 服务承诺」修改底栏文字、背景色、字体、字号和颜色；支持显示/隐藏、拖动和上下移动。点击预览中的服务承诺文字，也能直接修改内容和背景色。局部文字样式仍优先于模块样式，点击「恢复模块样式」恢复继承。文字为空时自动隐藏。

旧配置首次加载自动补入服务承诺模块，不覆盖其他模块。配置、模板和 JSON 备份可携带该模块；编辑保存后，当前配置图片同步重新生成，单张 PNG 与批量 ZIP 使用同一排版。更新工作台前请先保存当前编辑，刷新后重新导出以取得新版图片。

## 隐藏配件与统一配色格式

- 在「配件配置」每行下方取消「配置图显示」，仅在方图、详情图及图片导出中隐藏这一行（连同升级说明、质保和数量标签），保留配件记录、核算成本和维护表横向输出；勾选即可恢复。模板和备份保留此开关。
- 在「模块与样式 → 整体配色」调整画布背景、配件底色、主体文字、强调色、辅助文字和分隔线。主体文字色会清除普通模块及局部颜色覆盖；服务承诺单独设置。
- 先把当前配置调成目标样式，再点「批量配色与格式」。范围可以选择左侧已勾选配置，或直接选择全部配置。可分别勾选「全部配色」「全部格式」「机箱图片的位置、大小和显示开关」，页面会列出目标配置和套数。
- 格式包括方图/详情版式、字体、字号、字重、间距、模块顺序和模块显示状态。批量应用保留每套的配件、数量、价格、SPU/SKU、文案、机箱图片素材，以及每个配件的配置图显示开关。目标独有的文字模块保留；局部样式按相同配件槽位或模块同步。
- 应用后自动保存并更新所选配置图片，可使用「撤销」恢复本次修改。批量导出仍使用预览区当前选择的版式和主题。

# 2026-09-16：配置配件与库存监控联动

## 0.2.10 批量同步加购与福利

在目标配置左侧勾选需要同步的配置，打开作为基准的配置，再点“批量配色与格式”。窗口中可分别勾选“同步加购与选配”“同步福利点”，应用范围为本店已勾选或本店全部配置。只同步内容时可取消配色、格式选项。

勾选项使用当前配置的完整列表替换目标列表；当前列表为空时会清空对应目标内容，窗口会提示条数。加购保留组合商品、各自数量、整组总价、统一描述及说明。目标没有相同 sourceId 的原配件时，复制为独立加购；存在相同原配件则保留关联。未勾选的内容保留。应用后按现有保存流程保存数据并更新图片，也可通过撤销回退。

## 0.2.11 添加图片来源

配置图预览右上角“添加图片”支持“从本地导入”和“从机箱图库选择”。本地可以多选 PNG/JPG；图库支持搜索和分类选择。两种方式都添加独立图片图层，不替换机箱主图。添加后可拖动、缩放、置顶或移除，保存后再次打开仍保留。

## 0.2.13 操作记录与内存升级

操作记录展示最近 7 天的本地保存和新版收到的云端变更，支持开始/结束日期筛选、分页和“定位修改”。云端使用实际成员标识与云端提交时间，内容仅展示摘要。其他电脑尚未同步的本地输入无法查看。旧版记录不包含定位信息，不补造历史。已删除配置无法定位到编辑页；其他记录跳转到当前配置或对应维护区。展示记录过期清理不删除云端同步协议所需的变更序列。

内存数量为 2，且升级文案含 *2、＊2 或 ×2 时，默认不在配置图片中展示这条升级。升级说明页保留橙色下拉候选，可手动选中恢复展示；选择后保存并重开仍保留。切换到其他内存商品或换成不同文案时重新判断。数量不是 2、非内存配件不受此规则影响。

## 0.2.14 配置顺序

同步记录携带配置顺序，接收时不再使用随机配置 ID 排序。旧版已打乱的同链接配置优先按 WPS 原行号恢复；缺少行号但名称均为唯一“配置数字”时按数字顺序恢复。总览、复制和导出使用同一配置顺序。
