# 修改落实记录

来源：用户《修改.doc》及后续“配置模板添加删除功能”的要求。

- [x] 商品链接下包含多套配置，支持展开/折叠。
- [x] 新增配置链接，创建后直接编辑或导入模板；同一链接可继续添加空白配置。
- [x] 模板保存整个链接的全部配置；调用时支持整组或部分配置多选，一次生成选中项。
- [x] 删除模板，并支持当场撤销和刷新后恢复；不删除已经生成的配置。
- [x] “售价”改成“到手价”，支持编辑，价格栏放在配件配置上方。
- [x] “按 V5 生成简称”改成“生成简称”，沿用原有生成规则。
- [x] 原“存为模板”位置改成“查看配置总览”；整组保存按钮放在链接信息区。
- [x] 总览显示配置编号、CPU、显卡、内存、硬盘、版本与到手价。
- [x] 配件名称输入框按内容高度自适应，长型号完整显示。

兼容：原配置记录与旧单配置模板保留；模板导入时创建新配置 ID，SKU 留空，SPU 使用目标链接值。未新增平台发布或多人登录功能。
