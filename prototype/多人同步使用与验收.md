# 多人同步与 Windows 桌面版实测

2026-09-17，桌面版 0.2.16。正式工作台已接入 CloudBase PostgreSQL，右上角“同步”管理多人同步。“一键同步库存 / ERP”负责采集库存，两者用途不同。

## 两台电脑开始使用

1. 关闭旧版工作台，双击 `release/DIY配置工作台-0.2.16.exe`。无需单独安装 Node.js，首次解压可能稍慢。
2. 启动先进入登录页，使用已开通的成员账号登录；未登录不能查看或修改工作台数据。
3. 升级会保留现有桌面数据。全新电脑登录后，点击右上角“同步”并选择“接收已有云端数据”。仅在云端尚无初始数据且本机资料已准备好时，使用“预览并发布本机数据”。
4. 首次发布或接收完成后再编辑。其他设备通过同一工作区接收配置、成本和原始素材。
5. 点击右上角“成员：姓名”，可切换账号或退出登录。退出前先保存本地编辑，随后返回登录页。

同一电脑支持切换同一工作区的成员。原账号有待同步修改、未确认提交或冲突时，需先以原账号完成同步和冲突处理，再切换，避免新账号代提交旧修改。退出不会删除本机数据；不支持在同一数据目录切换到其他工作区。

密码加密保存在当前 Windows 用户下，未写入 EXE 或本文。在 `prototype` 目录用 PowerShell 7 执行：

```powershell
& './复制同步测试密码.ps1' -Account A
# B 使用 -Account B
```

密码会复制到剪贴板；另一台电脑由你私下转交。不要把 DPAPI 文件当作跨机凭证。同一电脑可按上述成员入口切换 A/B 账号；跨设备同步可用两台电脑验证。

## 日常使用与数据

本机编辑先保存至 SQLite，再同步到云端。自动同步约每 30 秒检查一次，编辑后也会触发；右上角可立即同步、暂停、查看冲突和下载同步备份。登录会话仅保存在内存，重启后重新登录，已保存的配置和待同步修改保留。接收他人更新时保护正在输入的内容，冲突不静默覆盖。

数据固定保存在 `%APPDATA%/DIYWorkbench/data`，与 EXE 文件位置分开。升级时替换 EXE，保留此目录。初次导入和启用同步会自动备份。可在关闭程序后复制整个 data 目录作为本地完整备份。

配置、共享人工成本、店铺优惠券、输出源、模板、图库和 ERP 库存快照参与同步。ERP 快照的全部分块通过校验后才切换；人工核算价独立保存，三店引用同一真实 goodsId 的成本记录。

只有配置和图库引用的原始图片上传到私有素材桶，按内容哈希去重；新电脑按需下载并核对哈希。现有 119 条配置只引用 4 个不同原图地址，并非 119 张独立图片。生成的配置 PNG 和 ZIP 继续保存在本机。未缓存原图需要联网登录后下载。暂不自动删除云端原图。

正式同步备份包含记录、草稿、库存分块、业务状态和未确认提交，不含密码及图片字节。恢复需要原账号；原图由云端按需补齐。完整离线恢复应同时保留 data/assets。开发维护时可恢复到新目录：

```powershell
node restore-sync.mjs 'D:/备份/工作台同步备份.json' 'D:/工作/恢复工作台'
$env:DATA_DIR='D:/工作/恢复工作台'
$env:PORT='4191'
node server.mjs
```

## 0.2.2 加购关联、检查和批量维护

“升级与加购”中点击“编辑加购”，按商品名称或真实 ERP ID 搜索并选择商品，填写加购数量、加购价和描述。加购价是该数量的合计价；例如每把 39 元、报价数量 1，填写数量 1 和价格 39，推荐购买数量仍可写在说明中。

差价按“原配件价格 ＋ 加购价 − 新配件成本价”计算，ERP、核算两项分别使用对应价格。原、新配件单价均乘加购数量，加购价为该数量的合计价。负差价不足 50 元时黄色字体提示；达到 50 元时红色提示需要重新调整加购描述。未关联商品、缺价或缺成本显示待补充，不当成零。只提示，不阻止保存，也不自动改变整机成本和图片文案。描述开头金额与单件加购设置价不同会另行提示核对。

“原配件（随此配件替换而切换）”可选择当前配置中的配件。批量或单独替换该配件时，旧关联加购会移除，新输出源的加购描述、商品、价格和数量一并带入；如果另一槽位仍使用旧配件，旧加购继续保留。独立加购保留。当前原始数据有 40 条手动加购、0 条输出源加购，未猜测绑定关系；编辑旧加购时需要用户明确关联，或保留为独立加购。

“本店输出源维护”新增“一键检查加购差价”。维护输出源加购后，可仅保存输出源，或预览并同步到本店引用配置。只改加购关联商品、数量或价格也会进入差异预览。

“批量修改”新增“批量修改加购描述”，范围为本店当前勾选配置；跨链接批量修改内的“批量修改本店加购描述”覆盖本店在用配置。先选择加购，再修改描述/说明，预览后应用。默认保留各条原有商品、数量和加购价；需要统一这些信息时勾选对应选项。原未关联的加购必须先明确关联。输出源和模板不会因批量修改配置加购而自动变化。

本版本保留 0.2.1 的桌面图标。100 项单元测试、5 项浏览器操作和 5 项实际 Electron 桌面操作通过，结果见 `verification/results/addon-unit.log`、`addon-ui-live.json`、`addon-desktop-live.json`。测试使用独立合成数据目录；原始业务 state.json 未修改。此次没有切换正式云端成员或写入正式业务数据。

## 0.2.4 差价公式修正与 ERP 星号排除

加购检查已补上原配件价格。输出源编辑使用当前配件价格；配置编辑使用关联原配件；批量检查逐套使用各自原配件及报价。原配件未关联或缺少价格时提示补充，不按零计算。负差价小于 50 元标黄，达到 50 元标红。界面展示完整算式，修改原核算价后立即刷新。

每次 ERP 完整导入校验通过后，名称包含 `*` 的配件自动排除，不论星号后是空白、`!` 或任意文字；兼容全角星号 `＊`。新增标记配件不进入成本源，已存在的标记配件从可用数据源排除，店铺别名不能绕过 ERP 原名规则。输出源、成本维护及加购搜索不提供这些配件。已有配置保留配件及成本快照；ERP 去掉标记后，可在后续同步重新进入可用数据源。

本次使用合成数据验证公式边界、批量检查、重复 ERP 导入排除及同步往返保留配置成本。原始业务数据未修改。

验证结果：103 项自动测试、7 项实际 Electron 桌面流程通过，包含连续两次完整 ERP 导入。记录见 verification/results/formula-unit.log、formula-desktop-live.json。

## 0.2.5 三店加购集中维护

输出源维护中的加购模块按当前配件 ERP ID 展示英特尔、技嘉、乔思伯三个区块。默认勾选当前店铺，可点击“只修改当前店铺”或“选择三店”，也可逐店勾选。每个店铺只展示自己的加购价和加购描述输入框；未勾选店铺保持原值。

加购商品、数量和说明合并到“共同信息”。只改价格或描述时，各店原有共同信息保留，即使三店之前设置不同也不会被覆盖。编辑共同信息后，会自动勾选“将共同信息应用到勾选店铺”；也可以主动勾选，将当前显示的共同信息统一到目标店铺。商品继续采用输入后直接展示搜索结果。

点击“保存输出源与勾选店铺加购”一次保存。原有的下方配置同步仍只作用于本店所选范围，其他店的已有配置不自动改动。其他店不存在对应 ERP ID 或对应多条输出源时，会提示核对，避免猜测关联。黄、红差价规则及 ERP 星号排除规则继续生效。

106 项自动测试、三店隔离保存与共同信息验证通过；测试使用独立合成数据，未修改原始业务数据。

## 0.2.6 核算优先与全部差异导出

加购差价优先展示核算，再展示 ERP。每项仍按自身差价着色，只有两项均为红色（各自差价均 ≤ -50 元）才显示“需要重新调整加购描述”。一键检查的汇总与排序按核算结果为主；例如 ERP 差价 -101 元、核算差价 +99 元，不提醒调整描述。

“预览差异 / 同步配置”已移到输出源维护最顶部。先保存配件资料，然后“预览本店全部差异”，会扫描本店所有已保存输出源与配置的差异，按配置列出修改前后值，不受左侧当前选择的配件限制。

选择“否，仅更新配置数据”，应用全部差异但不生成图片。选择“是，全部生成并导出”，应用全部差异，并为每套有差异的配置生成配置清单图与 SKU 图（1400 像素），保存在本地后打包下载。ZIP 按商品链接与图片类型分文件夹，附导出结果.json；生成失败会列出失败项，可点击重试。无差异配置及其他店铺配置不在本次导出范围。

110 项自动测试通过。浏览器已验证跨两个不同输出源汇总差异、生成并保存 4 张图片及 ZIP 内容、选择否不生成图片、再次扫描无差异。

实际桌面验证通过：顶部导出 3 项流程、加购与同步 7 项流程；最终便携 EXE 启动通过。结果见 verification/results/source-export-desktop.json、dual-red-desktop-live.json、desktop-portable.json。

## 0.2.7 独立桌面启动

桌面版使用自己的用户数据目录，不从旧工作台导入任何数据。首次启动直接进入空工作台，可自行创建资料或使用右上角同步登录云端。已有桌面数据在升级时保留。

桌面后台默认使用本机 4179 端口，与旧工作台分开。端口被占用时自动选择空闲端口并记住，重复启动只唤起已有窗口。关闭窗口前等待配置保存，关闭后退出内置后台并释放端口。保存冲突时保留窗口，处理后再关闭。

ERP 同步请重新安装桌面窗口中提供的脚本，它会自动使用该桌面工作台的地址。旧浏览器工作台及其数据不受影响。

验证：110 项自动测试及 5 项实际桌面启动测试通过，涵盖端口占用、空数据、脚本地址、单实例、关闭释放端口与重启持久化。

## 0.2.16 登录身份校验并发修复

修复 SDK 登录期间触发令牌刷新，导致重复身份校验并提示“正在切换登录状态，请稍后重试”的问题。手动登录完成前不额外发起刷新校验；登录后的刷新请求按顺序执行。退出时取消尚未发送的刷新请求。使用当前云端用户名和密码登录，已有本机数据及工作区绑定保留。
