公开分发包说明
本包使用占位云配置，不包含现有团队账号和生产云配置。
首次启动前由管理员编辑 _internal/web/.env.local，填写自己的 CloudBase 客户端配置，并开通工作区成员。
完整说明：https://github.com/yamakaze1234/diy-tools/blob/main/docs/部署与开发.md
离线文档：_internal/docs；架构图：_internal/docs/diagrams/architecture.html。

DIY 配置工作台 · Python 版 0.3.3

一、启动
1. 先正常退出旧版工作台，再将整个 ZIP 解压到固定文件夹。
2. 打开解压后的文件夹，双击 DIY配置工作台-Python-0.3.3.exe。
3. EXE 必须与 _internal 文件夹放在一起，不能只复制 EXE。
4. 不需要安装 Python、Node 或 SQL 驱动。支持 Windows 10/11 64 位。
5. 如果电脑提示缺少 WebView2，运行包内 MicrosoftEdgeWebview2Setup.exe，安装后再打开工作台。该微软官方安装程序需要联网。

二、界面与数据
保留原界面、配置图排版、图片预览、模板、图库和导出方式。
SQL 连接、云同步、本机保存、历史版本和后台任务改由 Python 处理。
配置计算与差异规则继续复用现有纯函数；运行时不启动 Electron 或 Node 服务。

默认业务数据位置：程序 EXE 所在文件夹\data
登录缓存与运行信息：程序 EXE 所在文件夹\data\runtime
不再默认把新数据写入 AppData。工具文件夹需要可写。
首次启动时，如果程序旁尚无 data 文件夹而 AppData 中存在旧数据，会自动复制迁入；旧目录保留。已有 data 时直接沿用，不覆盖。
升级请保留并沿用原工具文件夹中的 data；移动工具时连同整个文件夹一起移动。
首次切换至 Python 后台会自动备份旧 state.json、workspace.sqlite 和 versions.sqlite，位置记录于 data\python-backend-migration.json。
原有未同步修改、提交队列和历史版本沿用。请勿同时打开旧版和 Python 版操作同一数据目录。
Python 窗口使用独立的登录缓存，首次需要重新登录工作台成员账号。

三、换电脑
1. 使用已开通工作区权限的账号登录。
2. 全新空白电脑自动接收已有云端资料；已有本机配置时，通过“成员 → 接收已有云端数据”处理。
3. 在“ERP同步”中填写该电脑的 SQL 连接，读取并预览，核对后确认应用。
4. 勾选“在本机加密保存并自动填入”后，账号密码按 Windows 用户和工作台成员分别加密保存。

ERP 成本与可销数仅本机保存，不上传云端；每台电脑分别读取 SQL。
SQL 使用公司大库“分库可销数”和作为单件 ERP 成本的“库存成本”。人工核算价继续共享。
同一台电脑可读取旧版保存的 SQL 连接；另一台电脑仍需首次输入，密码不会随使用包转移。

四、使用说明
保存配置与关闭窗口时会等待当前编辑保存完成；保存失败时窗口保留，处理提示后再关闭。
普通编辑与图片操作自动保存在本机，不会随时上传云端。云端每两小时同步一次；需要马上共享时，打开“多人同步”点击“立即同步”。暂停自动同步时也可手动同步。
首次发布或全新电脑接收已有云端资料会立即执行。每次手动同步后重新计算两小时；关闭程序期间不运行，启动后到期才执行。
拖动图片会实时更新预览。普通保存先保存配置，停止操作并完成保存三秒后再生成 PNG；点击“保存配置”可立即生成。图库选图不必等待 PNG 生成后才能继续编辑。
云端同步状态显示下载进度；网络失败时本机修改和未确认提交保留，恢复后可继续同步。
下载 PNG 或 ZIP 时选择保存位置。_internal 内部文件不需要自行修改。
“多人同步 → 修改与提交记录”：
1. 本机修改记录：查看修改编号、登录成员、本机时间，以及每次保存的修改前后内容；从此功能启用后开始记录。
2. 本机 / 云端差异：只读查看同步基准、本机当前内容、云端当前内容和冲突字段。查看不会上传或覆盖本机。
3. 云端提交记录：查看唯一提交编号、服务器时间、成员 ID、记录版本和提交内容；一条业务记录对应一次提交。
本机保存不表示已上传。ERP 成本和库存不参与这些同步字段对比；云端其他成员暂显示成员 ID。
包内不含现有业务数据、工作台账号、SQL 密码或登录令牌。

五、版本验证说明
0.3.3 新增本机修改记录、云端提交记录与只读三方差异对比，沿用提交确认后再拉取的同步顺序。新包验证后端、记录与对比、登录保护、界面资源一致性和隔离环境启动；下列桌面操作与 SQL 验证为此前版本的验证记录。
0.3.2 新增两小时同步、随时手动同步、拖动预览缓存、本地保存与 PNG 生成分离。继续保留程序目录保存、旧目录迁移、已有 data 防覆盖、SQLite WAL 与旧加密凭据兼容。以下为 Python 版基础验收范围：
Python 后台：登录保护、旧数据备份、精确商品 ID、单件成本、预览确认、凭据隔离、历史还原、同步重试与冲突、分页回滚、SQL 等待期间状态响应等检查。
真实桌面：登录、接收配置、编辑保存、SQL 预览与应用、密码自动填入、PNG 生成、历史版本、账号切换、关闭前保存。
打包程序：移除 PATH 中 Python/Node 后独立启动与正常关闭，原界面文件一致，初始数据为空。
公司 SQL：仅只读查询验证成功，未应用或修改正式业务数据。云端读写流程使用隔离的模拟工作区验证。
