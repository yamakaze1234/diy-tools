DIY 配置工作台 v1.0.37｜新用户使用说明
更新日期：2026-09-27
完整教程：双击同文件夹内的「使用说明书.html」，可离线阅读、搜索和打印。

一、新用户首次使用步骤
1. 将整个 ZIP 解压到固定、可写的文件夹，不要在压缩包内直接运行。
2. 双击 DIY配置工作台-v1.0.37.exe。EXE 与 _internal 文件夹必须放在一起。
3. 支持 Windows 10/11 64 位，不需要安装 Python 或 Node。
4. 若提示缺少 WebView2，运行包内 MicrosoftEdgeWebview2Setup.exe（安装时需联网）。
5. 使用已开通工作区权限的成员账号登录。新用户专用包已配置团队登录，但不包含任何人的账号密码、业务数据或登录缓存。
6. 等待首次同步完成，确认左上角店铺正确；没有资料时先检查同步状态和工作区权限。
7. ERP 连接需要在每台电脑单独设置；ERP 成本和库存仅本机使用，人工核算价参与团队共享。

二、日常顺序
选店铺 → 新建或选择链接/配置 → 选择展示配件 → 核对实际配置、成本和售价 → 检查图片 → 保存到本机 → 导出；需共享时再执行同步。
点击配置名称决定当前编辑对象；左侧勾选决定批量操作范围，两者不同。
普通编辑自动保存，也可以点「保存到本机」。以保存成功提示为准。

三、链接、模板和配件
商品链接右侧「⋯」：删除所选、已删除配置、全部折叠。
每张链接卡片「⋯」：编辑链接、修改分类、卡片配色、恢复默认配色、删除该链接全部配置。
误删配置可在「已删除配置」中恢复；当前恢复期限为删除后 3 天。
主机模板与日常配置分区，点击主机模板区域再展开，可新增或编辑模板。
新建独立配置不会沿用勾选链接或旧机箱图片；复制配置排在原配置后面。
展示配件通过拖动调整顺序；图片是否显示配件不等于实际用料是否存在。
质保开关和配置图质保行已移除，空白模板不带质保字段。

四、输出源维护
左侧「工具与资料 → 输出源维护」。普通配件输入准确 ERP ID，读取产品名称和价格。
产品显示名称默认使用 ERP 名称，可以自行修改；修改名称不等于更换 ERP 商品。
新增时店铺选择默认为三个店铺全选，确认实际需要同步的店铺。
特殊配件使用特殊配件设置；WPS 导入后仍须核对识别结果、数量和成本。
维护输出源后，预览已有配置差异再同步；可按加购选项查看，并批量保留原描述。

五、批量处理
先核对左侧已选数量，再打开「批量修改与维护表」。
「批量修改配色与格式」可同步配色、编辑格式、机箱图片、加购、福利和版本。
「同步版本」默认不勾选；勾选后采用当前配置的版本名称，当前为空则清空目标版本。
仅想修改版本时，先取消其他不需要的选项。应用前再次确认所选范围。
批量修改配件与批量修改加购描述是不同操作，按预览结果确认修改范围。

六、检查与导出
利润检测不包含主机模板，仅显示异常，分为「成本缺失」「利润异常」，可直接定位配置。
库存检查可展开相关项并定位；未知库存不代表无库存。
主界面导出一张为 PNG，桌面版批量导图到所选文件夹；网页版批量导图为 ZIP。输出源差异同步的附带导图目前仍为 ZIP，请按具体入口提示核对。
导出后打开图片检查型号、价格、版本和排版。导出不会自动上传到销售平台。

七、保存、同步与故障
本机保存与云端同步是两步。需要新用户马上收到修改时，保存后点顶部「同步 → 立即同步」。
默认自动同步间隔为两小时；关闭程序期间不执行。
保存失败时不要立即刷新或强制退出，先保留当前输入并记录错误提示。
若关闭时提示将草稿保存到本机恢复文件，请选「是」；保留程序 data/recovery 中的草稿，交维护者核对恢复。
发生保存冲突时，可下载当前草稿，再重新比较；不要不看差异就覆盖。
v1.0.36 已优化大工作区保存时的内存使用，真实字段冲突仍会提示。

八、备份与升级
数据在程序同级 data 文件夹。正常退出后备份整个程序文件夹，至少保留完整 data。
升级前先备份，由维护者迁移数据；不要把新用户包覆盖到正在运行的程序上。
不要只移动 EXE、只复制快捷方式或删除 _internal、data 文件夹。
新用户分发请使用标注「组内新用户使用」的包，不要复制自己的 data、登录缓存或 SQL 凭据给新用户。

九、工具与资料——逐项详细操作

先确认店铺和本次范围。当前正在编辑的配置、左侧勾选、弹窗内勾选并不是同一个概念。

9.1 返回当前配置
用途：快速回到正在编辑的配置位置。
入口：左侧“工具与资料 → 返回当前配置”
范围：定位入口，不修改配置内容。
1. 先看左侧“正在编辑”卡片，确认当前店铺、链接和配置名称。点击配置名称与勾选复选框是两种操作：前者决定编辑谁，后者用于批量选择。
2. 在左侧展开“工具与资料”，点击“返回当前配置”，回到配置列表所在位置。
3. 继续操作前核对中间编辑区的配置名称；需要换一套配置时，在左侧点击那套配置的名称。
结果核对：继续编辑原来的配置，已有批量勾选不会因此清空。
例子：查完资料想接着修改配置 3，可以从这里返回；不是新建一套配置。
注意：它是定位入口，不执行保存、撤销或云端同步，也不负责重置搜索条件。

9.2 配置模板
用途：从本店模板中挑选配置，添加到当前商品链接。
入口：左侧“工具与资料 → 配置模板”
范围：当前店铺的模板库 → 当前链接；模板不跨店混用。
1. 先选对店铺，再点击需要接收配置的商品链接。若还没有链接，先新建链接；不要只勾选一个链接就认为它是导入目标。
2. 打开“工具与资料 → 配置模板”。先核对顶部“当前店铺”和“添加到”的链接名称；若提示统一本链接分期设置，先完成链接设置。
3. 模板组默认收起。搜索模板或配置名称，点“展开”查看；可勾选组标题旁的复选框整组选中，也可只勾选组内几套配置。
4. 确认底部“已选 N 套”，点击“添加所选配置”，等待添加并保存完成。
5. 打开新配置逐一检查：配件、数量、售价、版本和图片是否符合本次商品；导入使用目标链接的 SPU，SKU 留空，需要补齐真实 SKU。
6. 要建立可反复使用的模板，可在当前链接的“更多”中“整组存为模板”；要维护主机模板，可展开左侧“主机模板”区域新增或编辑。模板列表的删除项可在“已删除模板”中恢复。
结果核对：所选配置作为新副本加入目标链接。以后修改这份副本，不应当当作已经修改了模板库。
例子：新链接需要 14600KF 和 14700KF 两套配置：展开对应模板，只选这两套再添加，不必导入整组。配置简称用于快速识别，例如 14600KF+无卡+32G+1T丨进阶版。
注意：“配置模板”用于调用模板，“主机模板”区域用于维护模板。想从空白开始时使用“新建独立配置”，并核对创建后的所属链接；无需借用模板再逐项删除旧图片。

9.3 机箱图库
用途：先整理素材，再在配置中选用图片。
入口：左侧“工具与资料 → 机箱图库”
范围：图库三店共用；更换图片时作用于当前配置。
1. 打开“工具与资料 → 机箱图库”，用品牌、型号、颜色、版本或图片名称搜索，也可以沿左侧分类查找。
2. 新增素材：点“＋ 新增图片”，选择 PNG/JPG（最大 24 MB），填写图片名称、品牌、型号、颜色、版本，再点“保存图片”。没有版本区分可填“通用”。
3. 点图片查看大图、分类及“几套配置使用”。选“编辑资料”可修改图片名称和分类；保存后从新分类查找。
4. 要用于配置，先回到该配置，再从右侧“更换机箱图”的图库选图入口进入，选择“使用图片”。更换主机箱图会保留该配置原来的图片位置和大小。
5. 若要保留原图再加一张，使用图片编辑中的添加图片入口，从图库添加独立图片，再调整位置与大小。
6. 不用的素材可“删除图片 → 确认移入回收站”；恢复时在图库“回收站”选择“恢复图片”。
结果核对：图库里能按分类找到素材；选图后在右侧预览检查机箱颜色、完整外形、位置和大小。
例子：同型号有黑、白两色：分别填写颜色并使用清楚的图片名称；换白色配置时选白图，而不是只改文字。
注意：直接从“工具与资料”进入是管理图库，不会仅因点击缩略图就替换配置图片。图库删除会保留已有配置和模板的原图引用。

9.4 批量修改配件 / 加购 / 导图
用途：一次替换多条链接中的同一配件，或只修改逐项升级说明。
入口：左侧“工具与资料 → 批量修改配件 / 加购 / 导图”
范围：本店日常配置；在弹窗内选链接、看预览，不仅看主界面勾选。
1. 打开此入口，弹窗标题为“批量修改配件与导图”。先确认店铺，搜索原配件名称、ERP ID、链接或 SPU；需要时用配件类别缩小范围。
2. 选择原配件后核对匹配链接和套数。匹配链接可能已经全部勾选，请取消本次不需要改的链接。主机模板不参与这个日常配置批量入口。
3. 搜索并选中替换配件，核对准确 ERP ID。“统一数量”留空表示保留每套原数量；填正整数则统一为该数量。
4. 点击“预览修改”，检查原配件→新配件、数量、涉及链接与配置。显示配件和对应实际配置会受影响；逐项升级说明是否变化，以预览后的配置为准，不要把它等同于人工加购整组同步。
5. 确认后点“应用修改”，等待保存完成。若勾选“保存后导出所选链接的配置清单图和 SKU 图”，会生成所选链接内全部配置的图片，范围可能大于实际替换的配置。桌面版可保存到文件夹，网页版下载 ZIP。
6. 只想改文字时，使用弹窗里的“只修改加购描述”。可按原配件筛选，也可在“只搜索加购描述”输入旧文字；选链接，填写新描述（留空会清空），先预览再应用。此功能只改展示配件的“逐项升级说明”，保留人工“加购与选配”、实际配置和输出源。
7. 导图失败时先看是否已经提示修改保存成功。已保存的修改无需重复应用，可用“导出刚修改的链接图片”重试导出。
结果核对：打开一套被修改的配置，核对展示配件、实际配置、数量、成本和升级文字；需要共享时保存后再云端同步。
例子：把选定链接里的 A 内存换成 B 内存：不填统一数量，可保留各套原先的 1 根或 2 根。若只是把“升级内存”改成新文案，应走“只修改加购描述”。
注意：名称搜索后必须选中正确商品。预览确认的是这次会修改的对象；导出的图片还要单独检查，不会自动上传到销售平台。

9.5 输出源维护
用途：建立配件资料，并决定哪些旧配置跟随更新。
入口：左侧“工具与资料 → 输出源维护”
范围：资料按店铺维护；新增可选三个店铺，更新旧配置需另做差异同步。
1. 打开“工具与资料 → 输出源维护”，确认当前店铺。搜索配件名称或 ERP ID，编辑已有资料，或新增配件。
2. 新增普通配件时填写准确 ERP ID，读取 ERP 产品名称与单价。产品显示名称默认使用 ERP 名称，可基于它修改；检查 ID 和实时查询结果是否对应正确商品。查询失败、无价格时先处理数据来源，不要把未知当作 0 元。
3. 检查新增时的店铺勾选：默认三个店铺全选。只需部分店铺时取消对应选项；保存前确认最终范围。特殊项目使用“特殊配件”设置，不能把它当成已绑定普通 ERP 商品。
4. 维护显示名称、含税核算单价和逐项升级说明等需要的资料。看顶部“待保存修改”，点击“保存全部更改”；未保存资料不能作为旧配置差异比较的依据。
5. 找到“更新本店全部差异配置”。只勾选本次要更新的字段：“显示名称”“含税核算单价”“逐项升级说明”。默认是仅更新配置数据，暂不导图。点击“预览本店全部差异”。
6. 预览默认按“加购选项 / 相同差异”归类，也可切到“按链接”。展开“选择同步链接”确认范围；原值和新值相同的一类差异可一起查看，无需逐套展开。
7. 想保留现有文案，勾选“已选链接全部保留原描述”；也可用“保留此组选项原描述”或逐项“保留原描述”。它控制名称/升级文字，不表示保留含税成本；不更新成本应取消上方“含税核算单价”。已有手写内容默认保留，仍需核对预览。
8. 确认差异与数量后点“同步所选差异配置”。这里是把已保存输出源应用到本店配置；需要其他电脑收到时，还要执行顶部云端同步。
9. 若同时选择生成图片，本入口目前导出 ZIP，内含配置图、SKU 图及“导出结果.json”。先核对成功/失败数量；必要时“重新保存并导出”。若只要文件夹出图，可先仅同步数据，再从主界面的图片导出入口导出。
结果核对：配件资料已保存；只有预览中确认的旧配置字段被更新。打开一套配置检查文字、单价和图片效果。
例子：把散热升级说明统一改成新文案，但保留某链接已有手写说明：只选“逐项升级说明”，预览后按链接保留该链接原描述，再应用其余差异。
注意：维护表的“加购描述”在这里对应配件的逐项升级说明，不会新增或重写人工“加购与选配”的商品组合、价格和数量。只改某一张图的名称，可直接在该配置的“展示名称”改，不必改全店资料。

9.6 三店共用成本价
用途：维护同一 ERP 商品的人工含税核算单价。
入口：左侧“工具与资料 → 三店共用成本价”
范围：按 goods_id 在三店共用；会更新引用配置的核算成本。
1. 打开“工具与资料 → 三店共用成本价”，弹窗标题为“成本源维护”。搜索 goods_id（即 ERP 商品 ID）或名称，先核对型号。
2. 区分两列：ERP 成本和库存由 ERP 同步读取；“含税核算单价”是人工维护的单位价格。本入口编辑的是后者。
3. 单条修改：在目标行输入每件配件的含税核算价并保存。输入配件单价，整机按实际数量计算；不是把整机成本填在某一个配件上。
4. 多条修改：点“批量粘贴核算价”，优先从表格复制两列“goods_id＋含税核算单价”。若只粘贴一列价格，须先选中产品，按表格原有行顺序对应，不是按勾选先后对应。
5. 点“预览修改”，逐行看 ID、原价、新价和未匹配项；空白保留原价。遇到 #VALUE!，程序会尝试采用可用 ERP 成本，没有可用值时保留原核算价，务必在预览核对。
6. 确认后点“保存 N 条并更新引用配置”。检查引用配置的含税总成本和核算利润；其他电脑接收共享核算价还需要云端同步。
结果核对：同一 goods_id 的人工核算单价统一，引用它的配置重新核算；售价仍需按业务需要单独调整。
例子：内存单根含税价从 300 改为 320 元，一套实际使用 2 根的配置，其该项核算成本从 600 变成 640 元。
注意：ERP 成本与人工含税价是两种口径。不要因为两列不同就直接覆盖；更改本表也不是修改 ERP 系统价格。

9.7 检查商品库存
用途：找出本店配置里的无库存、低库存和未知库存配件。
入口：左侧“工具与资料 → 检查商品库存”
范围：读取本机最近一次 ERP 库存；替换配件须另选范围并确认。
1. 需要最新数据时，先点顶部“ERP 同步”，确认完成并查看库存时间，再进入“工具与资料 → 检查商品库存”。
2. 核对当前店铺和“低库存阈值（≤）”。首次默认 5，之后可能保留上次设置；例如设 5，表示库存小于等于 5 时关注。改阈值后点“重新检查”。
3. 先看统计，再按配件卡片查看“无库存”“低库存”和单独收起的“库存未知”。主机模板不参与；特殊配件跳过，图片中隐藏的普通配件仍检查。
4. 卡片默认收起，可搜索配件、ERP ID 或关联链接。展开后点“定位配置”，查看该配件实际出现在哪一套、哪个位置以及数量。
5. 要换缺货件，点对应卡片“勾选链接并替换”，在弹窗内勾选需要改的链接，选择新配件，再预览。检查实际配置和加购原/新内容，不要只看新配件名称。
6. 确认预览后再应用。若选了导图，核对所选链接全部配置的导出范围；修改后重新检查库存并检查整机成本。
结果核对：得到基于本机库存快照的异常列表；确认替换后，对应配置中的用料才发生变化。
例子：某散热库存为 3、阈值为 5，列为低库存；另一配件显示未知，应先检查 ID 和 ERP 读取结果，不能按无库存处理。
注意：本功能检查和修改的是工作台配置，不会自动修改销售平台库存或上下架。ERP 同步之后仍要重新检查，旧报告不会变成实时库存。

9.8 一键检测利润
用途：批量发现成本缺失与利润异常，直接定位处理。
入口：左侧“工具与资料 → 一键检测利润”
范围：本店日常配置，主机模板不参加；只展示异常结果。
1. 先核对实际用料、数量、到手价和分期，保存当前编辑，再打开“工具与资料 → 一键检测利润”。
2. 看清“已选 N 套”：左侧已有合格配置勾选时，默认采用这些配置；没有时默认选择本店全部合格配置。可搜索链接、SPU 或配置名称，按组选择；收起分组不等于取消勾选。
3. 点“开始检测”，等待保存和 ERP 成本读取完成。ERP 连接失败或价格资料不全时，应按结果提示处理，不能视为检测通过。
4. 检测后先处理“成本缺失”：用“定位配置”进入配置的成本区域，检查未绑定/未识别商品、缺少的人工含税价或 ERP 读取失败。补齐并保存后重新检测。
5. 再看“利润异常”：区分“核算利润”和“ERP 利润”，核对到手价、分期、数量、单价及变化金额。当前规则分别提示亏损超过 300 元、累计变化绝对值超过 100 元的情况，不显示正常配置的长明细。
6. “查看历史”用于对比历次检测。同一套配置可能同时存在成本缺失和另一口径利润异常，因此分类数量不一定能直接相加当作独立配置数。
7. 确定一次成本或定价变化是业务认可的新起点后，才使用“重设此口径变化基准”。它只调整后续比较起点并保留历史，不会补成本、改售价或修复亏损。
结果核对：异常逐项定位、修正、重新检测；没有异常时仍核对本次检测套数与所选范围，确保该检查的配置都检查了。
例子：某套显示“成本缺失”，先补该配件单价再复检；有完整成本但利润偏低，则核对售价、分期和实际配件，不能靠重设基准解决亏损。
注意：ERP 与核算利润的有效性分别判断。首次没有历史比较值不等于涨跌为零。“发布到后台监控”是额外文件发布功能，只有需要接入既有监控流程时再配置。

9.9 导出库存监控清单
用途：把配置用料整理成外部库存监控能导入的 CSV。
入口：左侧“工具与资料 → 导出库存监控清单”
范围：本店所选链接内全部配置的实际用料；按 goodsid 去重。
1. 打开“工具与资料 → 导出库存监控清单”。搜索链接名称、分类或 SPU，在弹窗内勾选链接；“全选筛选结果”只针对当前显示的链接，开始前可用“清空选择”。
2. 查看汇总：已选链接数、配置数、唯一 goodsid 数、合并的重复数量。同 ID 在多套配置中出现只导出一行；名称不同但 ID 相同仍按 ID 合并。
3. 填写“统一预警值”，默认 10。它是交给库存监控的提醒阈值，不是这套配置使用了几件，也不是为整机预留库存。
4. 核对预览和“缺少有效 ID，已跳过”的明细。实际配置中图片隐藏的配件仍计入；缺少或无效 goodsid 的项目不会导出，可先回配置补齐准确 ID。
5. 点击“导出监控 CSV”，保存文件。每次最多 5,000 个配件、10 MB，超限时分批选链接。
6. 打开配套的后台库存监控工具，选择“导入产品”，直接选择 CSV，核对匹配总览后确认。按 goodsid 精确匹配公司大库可销数；已有监控项更新预警值并保留原启用状态。
结果核对：得到可导入的 CSV；在库存监控工具确认导入与启用状态后，才进入相应监控流程。
例子：同一块硬盘被 20 套配置引用，清单只保留一个 goodsid，并保留来源信息；导出行数少于配置配件出现次数是正常去重。
注意：导出清单不会直接启动监控，也不包含实时库存查询结果。优先将原 CSV 直接导入；用表格软件改写 ID 时注意不要丢失长数字精度。

9.10 查看操作记录
用途：确认近期谁改了什么，并定位到当前配置。
入口：左侧“工具与资料 → 查看操作记录”
范围：最近 7 天的本机记录与已同步收到的云端记录。
1. 打开“工具与资料 → 查看操作记录”。程序会先保存待处理编辑并读取记录，保存失败时先处理保存提示。
2. 按日期范围查找，使用分页查看更多；核对操作时间、操作人、店铺/配置和修改摘要。
3. 有“定位修改”的记录可点击进入相关对象，检查当前内容。旧记录若没有定位信息，可能没有该按钮。
4. 若要核对其他成员刚做的修改，先完成云端同步再查看。尚未同步收到的操作不会凭空出现在本机记录里。
5. 需要撤销或恢复数据时，转到对应的撤销、已删除配置或历史版本入口，先检查目标；操作记录本身不是恢复按钮。
结果核对：能将一次近期操作与具体配置对应起来；定位看到的是配置当前状态。
例子：想确认昨天谁批量换了内存：筛选昨天，查看批量修改摘要和操作人，再定位其中一套配置核对现有用料。
注意：操作记录不是长期完整档案；“定位修改”不会把配置还原成当时版本。要恢复旧版本，仍需比较具体差异。
