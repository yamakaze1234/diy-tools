# 配置工作台 · 轻量网页版 1.0.2

这是成员登录版，使用已有工作台账号。发布包不含示例工作区、用户登录缓存、SQL 密码或本地业务数据。

## 静态托管

将 `static` 文件夹中的文件上传至静态托管，打开服务商提供的 HTTPS 地址即可，不必购买域名。首页就是成员登录页。

首次正式托管需要在现有云端认证中允许该站点地址。此包已完成构建，尚未上传至公网；取得实际托管地址后再做真实登录和同步验收。

静态版支持配置、模板、输出源、加购维护、利润查看及云端同步。右上角 ERP 同步支持从 ERP 页面直接接收库存，也可粘贴数据或导入库存 JSON；浏览器不能直接连接 SQL。

## 本机运行（需要 SQL 同步时）

电脑需要 Node.js 22 或更新的受支持版本。在 `local` 文件夹打开终端：

```sh
npm ci --omit=dev
npm start
```

然后打开 http://127.0.0.1:4196/cloud.html 。Windows 也可在安装依赖后双击 `start.cmd`；Mac / Linux 可执行 `sh start.sh`。保持运行窗口开启。

在右上角「ERP 同步 → SQL」填写公司数据库地址、数据库名和只读账号密码。电脑必须能够访问公司局域网数据库。只执行工作台固定库存查询，不写入 ERP 数据库；密码仅本次使用，不保存。

SQL 缓存保存在 `local/local-cache/inventory`，按成员及工作区隔离。查询失败保留旧缓存。库存未知或成本不完整时，不当成零库存或零成本。

## ERP 网页脚本

安装包中的 `workbench-erp.user.js`，或在网页 ERP 同步窗口下载 0.2.4。沿用工作台的账号、公司大库及成本列设置，在 ERP「分库库存」页面点击「下载网页版快照」。回网页版点击「ERP 同步 → 选择 ERP 库存快照」，选择 JSON 文件，核对账号、仓库、成本列和差异，再确认应用。脚本菜单也可下载快照；桌面工作台的本机采集通道保持不变。

## 保存与同步

编辑后先保存配置，再点击右上角云端同步。云端首次登录先下载数据。ERP 库存和成本保存在当前浏览器，不随配置上传云端。配置图不在网页版编辑。

模板沿用工作台排序；勾选导入按列表顺序追加并连续编号，不按勾选先后排列。配件名称可直接输入搜索，结果显示库存和价格；特殊配件仅展示、不计成本。

## 升级与保留数据

静态站点升级保持原地址；本机版保持原端口和浏览器。不要清理浏览器站点数据。升级本机版时保留旧 `local-cache` 文件夹及原包备份，再替换程序文件。更换电脑或浏览器前，先完成配置云端同步；ERP 快照需要单独重新导入或查询。

## 本版验收范围

构建、业务单元测试及隔离浏览器流程已验证。隔离测试没有向生产云端写测试数据。尚未进行公司真实 SQL 连接、生产双端写入、公网托管及 Mac / Linux 实机验收。
